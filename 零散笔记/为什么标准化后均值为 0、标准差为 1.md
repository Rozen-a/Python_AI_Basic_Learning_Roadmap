# 为什么标准化后均值为 0、标准差为 1

下面**一步一步、从定义出发**说明三件事：
**① 标准化是怎么做的**
**② 为什么标准化后均值为 0**
**③ 为什么标准化后标准差为 1（给出严格证明）**

------

## 一、什么是标准化（Z-score）

给定一组数据：

$X = {x_1, x_2, \dots, x_n}$

定义它的：

- 均值
    $\mu = \frac{1}{n}\sum_{i=1}^n x_i$
- 标准差（总体标准差）
    $
    \sigma = \sqrt{\frac{1}{n}\sum_{i=1}^n (x_i-\mu)^2}
    $

**标准化的定义**是对每一个数据点做如下变换：

$
\boxed{z_i = \frac{x_i - \mu}{\sigma}}
$

这一步包含两层含义：

1. **减去均值** → 把“中心”移到 0
2. **除以标准差** → 统一尺度（消除单位）

------

## 二、证明：标准化后均值为 0

标准化后的数据为：

$
Z = {z_1, z_2, \dots, z_n}, \quad z_i=\frac{x_i-\mu}{\sigma}
$

标准化后的均值：

$
\bar{z} = \frac{1}{n}\sum_{i=1}^n z_i
$

代入定义：

$
\bar{z}
= \frac{1}{n}\sum_{i=1}^n \frac{x_i-\mu}{\sigma}
$

把 (\frac{1}{\sigma}) 提出来：

$
\bar{z}
= \frac{1}{\sigma}\cdot \frac{1}{n}\sum_{i=1}^n (x_i-\mu)
$

而根据均值的性质：

$
\sum_{i=1}^n (x_i-\mu) = 0
$

所以：

$
\boxed{\bar{z} = 0}
$

✅ **证明完毕：标准化后均值一定是 0**

------

## 三、证明：标准化后标准差为 1

标准差的定义（总体）：

$
\sigma_z = \sqrt{\frac{1}{n}\sum_{i=1}^n (z_i-\bar{z})^2}
$

由于上一步已经证明：

$
\bar{z} = 0
$

所以：

$
\sigma_z = \sqrt{\frac{1}{n}\sum_{i=1}^n z_i^2}
$

代入 (z_i = \frac{x_i-\mu}{\sigma})：

$
\sigma_z
= \sqrt{\frac{1}{n}\sum_{i=1}^n \left(\frac{x_i-\mu}{\sigma}\right)^2}
$

把 (\frac{1}{\sigma^2}) 提出来：

$
\sigma_z
= \sqrt{\frac{1}{\sigma^2}\cdot \frac{1}{n}\sum_{i=1}^n (x_i-\mu)^2}
$

根据原始数据标准差的定义：

$
\frac{1}{n}\sum_{i=1}^n (x_i-\mu)^2 = \sigma^2
$

代入：

$
\sigma_z
= \sqrt{\frac{1}{\sigma^2}\cdot \sigma^2}
= \sqrt{1}
= \boxed{1}
$

✅ **证明完毕：标准化后标准差一定是 1**

------

## 四、直观理解（非常重要）

标准化做了两件事：

1. **减去均值**
    → 数据整体向左或向右平移
    → 不改变“形状”，只改变位置
2. **除以标准差**
    → 拉伸或压缩数据
    → 把“平均偏离程度”统一成 1

所以标准化的本质是：

> **把数据变成“以均值为 0、以标准差为单位的偏离量”**

------

## 五、一句话总结（考试 / 面试可直接用）

> 标准化通过 (z=\frac{x-\mu}{\sigma})
> 先平移使均值为 0，再缩放使标准差为 1，
> 这是由均值和标准差的定义直接严格推导得到的。
