### 1. sigmoid

$$
f(x) = \frac {1}{1 + e^{-x}}
$$

求导：
$$
f'(x) = \left( \frac {1}{1 + e^{-x}} \right)' = \frac{e^{-x}}{(1 + e^{-x})^2} = \frac{e^{-x} + 1 - 1}{(1 + e^{-x})^2} = \frac{1}{1 + e^{-x}}\left( 1- \frac{1}{1 + e^{-x}} \right) = f(x) \cdot ( 1- f(x))
$$
**将任意输入映射到(0, 1)**，不以0为中心，范围[0, 1]

仅当输入值在0附近时，输出值才会有明显差异，输入值绝对值稍大时 sigmoid 函数的导数接近0，此时网络参数更新极其缓慢，易引发**梯度消失**

只适于层数很少的简单神经网络，一般用于二分类任务

### 2. Relu

$$
f(x) = max(0, x)
$$

求导：
$$
f'(x) = \begin{cases} 0 & x \le 0 \\ 1 & x>0 \end{cases}
$$

- **将小于 0 的值映射为 0， 大于 0 的值保持不变**
- 输入的负值会被舍弃，正值会被保留
- 能够在 $x>0$ 时保持梯度不衰减，从而**缓解梯度消失问题**
- 但出现部分输入 $x<0$ 时，由于梯度为 0 ，会导致相应权重无法更新，出现**神经元死亡**
- 会使部分神经元输出为 0 ，造成网络的稀疏性，减少了参数的相互依存关系，能够**缓解过拟合问题**

### 3. ELU

$$
f(x) = \begin{cases} x & x \ge 0 \\ \alpha (e^x - 1) & x < 0 \end{cases}
$$

- $\alpha$ 是一个正数，通常取1

求导：
$$
f'(x) = \begin{cases} 1 & x \ge 0 \\ \alpha e^x & x < 0 \end{cases}
$$

- 在 $x<0$ 时有负指数特性，而不是被舍弃，**能够避免神经元死亡**
- ELU 相对 ReLU 在负值计算时间更长，**对于一些复杂的任务效果会略微好于 ReLU**

### 4. SELU

SELU 就是在 ELU 的基础上乘以缩放系数 $\lambda$
$$
f(x) = \lambda \begin{cases} x & x \ge 0 \\ \alpha (e^x - 1) & x < 0 \end{cases}
$$

- **能够在一定程度上解决梯度消失和梯度爆炸问题**
