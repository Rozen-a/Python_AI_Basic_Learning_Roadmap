#### 1.6 张量的形状操作

*   `reshape()`: 调整形状
*   `transpose()`: 交换两个维度
*   `permute()`: 重新排列多个维度
*   `unsqueeze()`: 在指定维度上增加1个维度
*   `squeeze()`: 删除大小为1的维度
*   `view()`: 调整张量的形状，需要连续内存
*   `is_contiguous()`: 判断是否内存连续
*   `contiguous()`: 转换为连续内存

```python
import torch

x = torch.randn(2, 3, 4)
print(x.shape)
print(x.size())         # size() 方法和 shape 一样, 返回张量的形状

# 1. 调整形状
x = x.reshape(2, 12)            # 调整为2行12列
print("x.shape1:",x.shape)
x = x.reshape(-1, 3)            # 不限制行数, 列数调整为3列 (会自动计算行数)
print("x.shape2:",x.shape)

# 2. 交换维度
x = torch.randn(2, 3, 4)
x = x.transpose(1, 2)
print(x.shape)

# 3. 重新排列多个维度
# 第3维度变为第1维, 第2维变为第2维, 第1维变为第3维
x = x.permute(2,1,0)
print(x.shape)

# 4. 在指定维度上增加一个维度, 会添加形状为1的维度
x = x.unsqueeze(dim = 2)
print(x.shape)

# 5. 在指定维度上删除一个维度, 会删除形状为1的维度 (如果该维度不存在形状为1的维度, 则返回原张量)
x = x.squeeze(dim = 1)
print(x.shape)

# 6. 调整形状, 需要连续内存
# 经过升维和降维操作, 张量的数据存储位置 (内存) 可能会改变, 所以内存可能不连续
# 使用view方法, 如果内存不连续, 那么会报错
# x = x.view(3,-1)
# print(x)

# 6. 判断是否是连续内存
print(x.is_contiguous())

# 7. 转换为连续内存
x = x.contiguous()
print(x.is_contiguous())

# 8. 调整形状, 需要连续内存
x = x.view(3,-1)

```

#### 1.7 张量的拼接操作

*   `cat()`: 张量拼接，按已有维度拼接。除拼接维度外，其他维度大小须相同
*   `stack()`: 张量堆叠，按新维度堆叠。所有张量形状必须一致


### 2. 自动微分

训练神经网络时，最常用的算法就是反向传播。

在该算法中，参数（模型权重）会根据损失函数关于对应的参数的梯度进行调整。为了计算这些梯度，Pytorch内置了自动微分模块，具体来说就是名为 `torch.autograd` 的自动微分引擎，他支持任意计算图（计算图就是构建好的神经网络）的自动梯度计算：

![image-20260306021829265](https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260306021829380.png)

如何理解自动微分呢？大白话来说，其实就是**自动求梯度**

举个例子（以线性回归为例，如上图所示）

*   假设模型参数是：$y = w \cdot x + b$
*   现在提供了特征值x，目标值y
*   初始化随机 权重w和偏置b
*   通过模型 $y' = w \cdot x + b$ 可以得到拟合结果
*   然后对拟合结果与真实结果求得损失函数
*   接下来利用损失函数，对w和b求偏导，得到梯度下降的梯度

$$
w_n = w_{n-1} - \eta \frac{\partial Loss}{\partial w}
$$

$$
b_n = b_{n-1} - \eta \frac{\partial Loss}{\partial b}
$$



*   然后更新w和b，重新拟合

而自动微分模块，其实就是根据损失函数Loss自动求得权重w和偏置b的梯度。

接下来我们使用这个结构进行自动微分模块的介绍。我们使用 `backward()` 方法实现梯度的计算，`grad` 属性来访问梯度

```python
import torch

# 1. 准备数据：参数与目标值
x = torch.tensor(5) #特征
y = torch.tensor(0.)

# 2. 初始化参数：权重与偏置
w = torch.tensor(1., requires_grad=True, dtype=torch.float32)
b = torch.tensor(3., requires_grad=True, dtype=torch.float32)

# 3. 构建神经网络并输出值
z = w * x + b

# 4. 计算损失
loss = torch.nn.MSELoss()
loss = loss(z, y)

# 5. 反向传播，自动微分，计算梯度
loss.backward()

# 6. 访问梯度
print(w.grad)
print(b.grad)
```

```python
import torch

# 1. 准备数据：参数与目标值
x = torch.ones(2,5)
y = torch.zeros(2,3)

# 2. 初始化参数：权重与偏置
w = torch.randn(5,3, requires_grad=True)
b = torch.randn(3,requires_grad=True,)

# 3. 构建神经网络并输出值
z = torch.matmul(x, w) + b

# 4. 计算损失
loss = torch.nn.MSELoss()
loss = loss(z, y)

# 5. 反向传播，自动微分，计算梯度
loss.backward()

# 6. 访问梯度
print(w.grad)
print(b.grad)
```

### 3. PyTorch 训练模型一般步骤

通过 **PyTorch** 训练一个模型一般可以分为以下 4 个步骤：

**1. 准备数据**

- 自定义 `Dataset` 类
    - 实现`__init__(self)`：加载原始数据，保存数据处理需要的配置
    - 实现 `__getitem__(index)`：根据索引返回对应位置的样本数据
    - 实现 `__len__()`：返回数据集的总样本数
- 使用 `DataLoader` 加载数据
    - 设置 `batch_size`：按批次读取数据
    - 设置 `shuffle=True`：打乱样本顺序，避免模型陷入局部最优

**2. 构建模型**

- 使用 `torch.nn.Module` 搭建神经网络结构
- 在 `forward()` 方法中定义前向计算过程

**3. 定义损失函数与优化器**

- 选择损失函数（如：均方误差 `MSELoss`）用于衡量预测值与真实值的差距
- 选择优化器（如：`SGD`、`Adam`）用于更新模型参数

**4. 模型训练**

- 使用两层循环进行训练
    - 外层：`epoch`（训练轮数）
    - 内层：`step`（每个 batch 的训练次数）
        - `step ≈ 样本总数 / batch_size`
- 每个 step 的训练流程：
    1. 前向计算（`model(x)`）
    2. 计算损失（`loss`）
    3. 清空梯度（`optimizer.zero_grad()`）
    4. 反向传播求梯度（`loss.backward()`）
    5. 更新参数（`optimizer.step()`）

### 4. Dataset 和 DataLoader

一般案例中，送入模型中的是DataLoader中的一批一批的数据，而DataLoader中的数据是从Dataset数据集中获取的。在很多任务中，Dataset数据集已经有别的组织或者框架给我们封装好了，但是也有可能没有给我们封装好，有的时候我们也需要自己从原始数据封装为Dataset供模型训练。

#### 4.1 Dataset

Dataset是Pytorch中的一个抽象类，用于表示数据集。它**允许用户自定义数据集的接口，使得用户可以使用统一的形式来访问数据**。

举个例子：

*   Dataset就像“整理好的快递箱”
*   每个快递箱（Dataset）里装着多个包裹（样本）
*   每个包裹上贴了编号（索引）
*   快递员（DataLoader）能按编号快速找到并取出包裹，不用翻遍整个箱子

**定义方法：**

PyTorch 要求自定义Dataset必须继承 `torch.utils.data.Dataset`，并实现 **3 个核心方法** —— 这 3 个方法就是“数据容器的说明书”，告诉框架“数据有多少、怎么取”。

*   `__init__(self)`：加载原始数据，保存数据处理需要的配置，如样本的大小，总个数等。相当于“把所有包裹装进快递箱”
*   `__len__(self)`：作用是告诉框架，容器中有多少个样本，返回总样本个数即可
*   `__getitem__(self, index)`：通过数据的索引，获取样本。

```python
# 自定义Dataset
import torch
from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self):
        # 1. 初始化数据，例如读取文件
        self.data = ['李云龙','楚云飞','赵刚','丁伟','孔捷','常乃超','魏大勇','秀芹']
        self.total = len(self.data)

    def __getitem__(self, index):
        # 2. 获取索引对应的数据
        return self.data[index]


    def __len__(self):
        # 3. 返回数据集的长度
        return self.total

if __name__ == '__main__':
    dataset = MyDataset()
    print(dataset[1])
```

#### 4.2 DataLoader

DataLoader是 PyTorch 中用于批量加载数据的工具。
它允许用户根据自定义的Dataset对象创建一个数据加载器，用于**批量加载和处理数据**。
DataLoader可以**按照批次大小对数据集进行分割**，并**提供多线程数据加载和预取功能**。

```python
# DataLoader的创建
import torch
from torch.utils.data import DataLoader

# 创建DataLoader
# batch_size: 每次批次的大小（一般是2的倍数）
# shuffle: 是否打乱数据
dataloader = DataLoader(MyDataset(), batch_size=2, shuffle=False)
	# 每次取两个样本（Tensor）装箱，打包成一个data（Tensor）
    # 此处示例使用的是列表而非Tensor，所以返回data的类型也是list而不是Tensor

# 获取批次数据
for data in dataloader:
    print(data)
```

### 1. 人工神经网络（Artificial Neural Network，简写为ANN）

简称神经网络（NN）

来源不同树突（树突都会有不同的权重）的信息，进行加权计算，输入到细胞中做加和，再通过激活函数输出细胞值。

> **`nn.Linear()`全连接神经网络**：第 N 层的每个神经元和第 N-1层 的所有神经元相连
>
> 每一个神经元都相当于做一次**逻辑回归**（线性回归＋激活函 数）【也存在做其他处理的】

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307011116329.png" alt="image-20260307011116205" style="zoom:67%;" />

神经网络中信息只向一个方向移动，即从输入节点向前移动，通过隐藏节点，再向输出节点移动。每个连接都有一个权重值。

其中的基本部分是:

1. **输入层**: 即输入 x 的那一层（x 即**特征**）
2. **输出层**: 即输出 y 的那一层（y 即**标签**）
3. **隐藏层**: 输入层和输出层之间都是隐藏层

![image-20260307011257281](https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307011257368.png)

每一个神经元工作时，**前向传播**会产生两个值，**内部状态值**和**激活值**；**反向传播**时会产生**激活值梯度**和**内部状态值梯度**。

通过控制每个神经元的内部状态值、激活值的大小；每一层的内部状态值的方差、每一层的激活值的方差可让整个神经网络工作的更好。

### 2. 常见激活函数

#### 2.1 sigmoid 激活函数

激活函数公式：

$$
f(x) = \frac{1}{1 + e^{-x}}
$$
激活函数求导公式：

$$
f'(x) = (\frac{1}{1+e^{-x}})' = \frac{1}{1+e^{-x}}(1 - \frac{1}{1+e^{-x}}) = f(x)(1 - f(x))
$$
sigmoid 激活函数的函数图像如下:

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307012559282.png" alt="image-20260307012559177" style="zoom:67%;" />

从 sigmoid 函数图像可以得到，sigmoid 函数可以**将任意的输入映射到 (0, 1) 之间**，当输入的值大致在 <-6 或者 >6 时，意味着输入任何值得到的激活值都是差不多的，这样会丢失部分的信息。比如：输入 100 和输出 10000 经过 sigmoid 的激活值几乎都是等于 1 的，但是输入的数据之间相差 100 倍的信息就丢失了。

对于 sigmoid 函数而言，输入值在 **[-6, 6]** 之间输出值才会有**明显差异**，输入值在 **[-3, 3]** 之间才会有**比较好的效果**。

通过上述导数图像，我们发现**导数数值范围是 (0, 0.25)**，当输入 <-6 或者 >6 时，sigmoid 激活函数图像的**导数接近为 0**，此时**网络参数将更新极其缓慢，或者无法更新**。

一般来说，sigmoid 网络在 **5 层之内**就会产生**梯度消失**现象。而且，该激活函数并不是以 0 为中心的，所以在实践中这种激活函数使用的很少。sigmoid函数一般只用于==二分类的输出层==。

#### 2.2 tanh 激活函数

Tanh 叫做双曲正切函数，其公式如下：

$$
f(x) = \frac{1 - e^{-2x}}{1 + e^{-2x}}
$$
激活函数求导公式:

$$
f'(x) = (\frac{1-e^{-2x}}{1+e^{-2x}})' = 1 - f^2(x)
$$
Tanh 的函数图像、导数图像如下：

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307012843287.png" alt="image-20260307012843183" style="zoom:67%;" />

由上面的函数图像可以看到，Tanh 函数**将输入映射到 (-1, 1) 之间**，**图像以 0 为中心**，在 0 点对称，当输入 大概<-3 或者 >3 时将被映射为 -1 或者 1。其**导数值范围 (0, 1)**，当输入的值大概 <-3 或者 > 3 时，其导数近似 0。

与 Sigmoid 相比，它是以 0 为中心的，使得其**收敛速度要比 Sigmoid 快**，减少迭代次数。然而，从图中可以看出，Tanh 两侧的导数也为 0，同样会造成**梯度消失**。

若使用时可**在==隐藏层==使用tanh函数，在输出层使用sigmoid函数**。

#### 2.3 ReLU 激活函数

ReLU 激活函数公式如下：

$$
f(x) = \max(0, x)
$$
激活函数求导公式:

$$
f'(x) = 0\text{或}1
$$
函数图像如下:

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307013033081.png" alt="image-20260307013032976" style="zoom:67%;" />

从上述函数图像可知，ReLU 激活函数**将小于 0 的值映射为 0，而大于 0 的值则保持不变**，它**更加重视正信号，而忽略负信号**，这种激活函数运算更为简单，能够提高模型的训练效率。

但是，如果我们网络的参数采用随机初始化时，很多参数可能为负数，这就使得输入的负值会被舍去，而输入的正值则会保留，这可能在大部分的情况下并不是我们想要的结果。

ReLU 的导数图像如下:

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307013125528.png" alt="image-20260307013125433" style="zoom:67%;" />

ReLU是目前最常用的激活函数。从图中可以看到，当x<0时，ReLU导数为0，而当x>0时，则不存在饱和问题。所以，**ReLU 能够在x>0时保持梯度不衰减，从而缓解梯度消失问题**。然而，随着训练的推进，部分输入会落入小于0区域，导致对应权重无法更新。这种现象被称为**“神经元死亡”**。

与sigmoid相比，RELU的优势是：

*   采用sigmoid函数，计算量大（指数运算），反向传播求误差梯度时，求导涉及除法，计算量相对大，而采用Relu激活函数，整个过程的计算量节省很多。
*   sigmoid函数反向传播时，很容易就会出现梯度消失的情况，从而无法完成深层网络的训练。
*   Relu会使一部分神经元的输出为0，这样就造成了网络的稀疏性，并且减少了参数的相互依存关系，**缓解了过拟合问题的发生**。

#### 2.4 SoftMax

softmax用于多分类过程中，它是二分类函数sigmoid在**多分类**上的推广，目的是**将多分类的结果以概率的形式展现出来**。

计算方法如下图所示：

$$
softmax(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$
**整体作用:** 将分子除以总和，实现**归一化（Normalization）**，确保所有输出值的和等于 1

Softmax 直白来说就是将网络输出的 logits 通过 softmax 函数，就**映射成为(0,1)的值**，而这些值的**累和为1**（满足概率的性质），那么我们将它理解成概率，**选取概率最大（也就是值对应最大的）节点，作为我们的预测目标类别**。

#### 2.5 激活函数选择

对于**隐藏层**:

1.  优先选择ReLU激活函数
2.  如果ReLu效果不好，那么尝试其他激活，如Leaky ReLu等。
3.  如果你使用了ReLU，需要注意一下Dead ReLU问题，避免出现大的梯度从而导致过多的神经元死亡。
4.  少用使用sigmoid激活函数，可以尝试使用tanh激活函数
5.  **如果权重初始化采用Xavier初始化，可以选用tanh激活函数或sigmoid激活函数**
6.  **如果权重初始化采用kaiming初始化，可以选用relu激活函数**

对于**输出层**:

1.  二分类问题选择sigmoid激活函数
2.  多分类问题选择softmax激活函数
3.  回归问题选择identity激活函数

### 3. 交叉熵损失和均方误差损失对比分析（使用SoftMax） 

**均方误差(回归)公式**
$$
MSE = \frac{1}{n}\sum_{i}^{n}(\hat{y}_i - y_i)^2
$$
**交叉熵损失公式**
$$
L = \frac{1}{N}\sum_{i}L_i = -\frac{1}{N}\sum_{i}\sum_{c=1}^{M}y_{ic}\log(p_{ic})
$$
**均方误差与交叉熵损失对比：**

- **相同点：**当输出值与真实值接近的话，cross_entropy 和 rmse 的值都会接近 0
- **cross_entropy 具有 rmse 不具有的优点：**避免学习速率降低的情况。(注意这种效果仅限于输出层，隐藏层的学习速率与其使用的激活函数密切相关。)
- 主要原因是**逻辑回归配合 MSE 损失函数时，采用梯度下降进行学习时，会出现模型一开始训练时，学习速率非常慢的情况（MSE 损失函数）**

- **均方损失：**假设误差是正态分布，适用于**线性的输出(如回归问题)**，特点是对于与真实结果差别越大，则惩罚力度越大，这并不适用于分类问题
- **交叉熵损失：**假设误差是二值分布，可以视为预测概率分布和真实概率分布的相似程度。在**分类问题**中有良好的应用。

> 对于更小的概率，-log所得值越大（且增大的越快），那么预测错误时，1会乘上一个较小概率的log，使得对于该样本的损失值变得极大

结论：**交叉熵损失 更能捕捉到预测效果的差异，交叉熵损失相对于均分误差损失梯度更大，能够让模型更快收敛！**

### 4. **数据集为什么要划分为训练集、验证集、测试集**

**1. 训练集（Training Set）**
用于**训练模型参数**，让模型学习数据中的规律。

**2. 验证集（Validation Set）**
用于**调节超参数和选择模型**，并判断是否出现**过拟合**。

**3. 测试集（Test Set）**
用于**最终评估模型性能**，检验模型在**未知数据上的泛化能力**。
在最终评估前，测试集的信息是完全没有被模型获取过的。

**核心原因：**

- 避免模型只记住训练数据（过拟合）
- 保证模型评估结果**客观可靠**

**常见划分比例：**

- 训练集：60%~80%
- 验证集：10%~20%
- 测试集：10%~20%

**一句话总结：**

> **<span style='color:red'>为了防止人工调参造成的测试集的信息泄露</span>**

### 5. `nn.Linear()` 全连接神经网络

**第 N 层的每个神经元都与第 N−1 层的所有神经元相连**，因此称为**全连接层（Fully Connected Layer）**。

每个神经元的计算本质是一个**线性变换**：
$$
y = wx + b
$$
其中：

- $x$：输入特征
- $w$：权重矩阵
- $b$：偏置
- $y$：输出结果

如果在线性变换之后再接**激活函数**（如 ReLU、Sigmoid 等），就形成了一个完整的神经元计算过程，因此可以理解为：

> 每一个神经元都相当于做一次 **逻辑回归（线性变换 + 激活函数）**

在 PyTorch 中使用 `nn.Linear()` 来实现该层，因此也称为：

- **线性层（Linear Layer）**
- **全连接层（Fully Connected Layer）**

------

**输入数据要求**

`nn.Linear()` 只支持 **二维 Tensor** 输入，即 shape = (样本数batch_size, 特征数feature)

------

**高维数据的处理**

对于图像等高维数据（如 `(batch, channel, height, width)`），
在进入线性层之前需要先展开为一维向量，因此通常需要使用`nn.Flatten()`展开层

作用：

```
(batch, channel, height, width)
          ↓
(batch, channel × height × width)
```

即把多维特征**展开为一维特征向量**，才能输入到 `nn.Linear()`。

**简单示例**

```python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Flatten(),        # 展平
    nn.Linear(784, 128), # 全连接层
    nn.ReLU(),           # 激活函数
    nn.Linear(128, 10)
)
```

> 这里表示：784维输入 → 128个神经元 → 10维输出

### 1. $w$的初始分布

在神经网络训练开始前，需要对模型参数 **w（权重）进行初始化**。  
合理的初始化可以避免：

- 梯度消失
- 梯度爆炸
- 网络训练缓慢

常见的初始化方法有：

- **Kaiming 初始化（He 初始化）**
- **Xavier 初始化（Glorot 初始化）**

| 方法            | 公式                                              | 适用激活函数     |
| --------------- | ------------------------------------------------- | ---------------- |
| Xavier Uniform  | $\sqrt{\frac{6}{\text{fan\_in}+\text{fan\_out}}}$ | sigmoid / tanh   |
| Kaiming Uniform | $\sqrt{\frac{3}{\text{fan\_in}}}$                 | ReLU / LeakyReLU |

####  1.1 均匀分布（Uniform Distribution）

均匀分布也叫 **矩形分布**。

**特点：**在某个区间内，每个值出现的概率完全相同。

**数学定义**

如果随机变量随机变量X服从区间[a,b]上的均匀分布，即 $X \sim \mathcal{U}(a, b)$，则概率密度函数为：

$$
f(x) = \begin{cases} 
\frac{1}{b-a} & a \leq x \leq b \\
0 & \text{其他}
\end{cases}
$$

含义

- 区间 $[a, b]$ 内概率密度为常数
- 区间外概率为 0

##### 均匀分布与正态分布对比

在机器学习中常见两种随机初始化：

- **均匀分布（Uniform）**
- **正态分布（Normal / Gaussian）**

**区别对比**

| 分布     | 特点                   |
| -------- | ---------------------- |
| 均匀分布 | 区间内概率相同         |
| 正态分布 | 中间概率大，两边概率小 |

- 🔴 红色：均匀分布

#### 1.2 Kaiming_Uniform_ 初始化

`kaiming_uniform_` 是 **PyTorch 默认常见的权重初始化方法**之一。

官网默认公式是  $\sqrt{\frac{3}{\text{fan\_in}}}$

示例代码：

```python
w = torch.empty(128, 256)
nn.init.kaiming_uniform_(w, a=math.sqrt(5), mode='fan_in', nonlinearity='leaky_relu')
```

含义：

- `fan_in` ：输入神经元数量
- `fan_out`：输出神经元数量
- `a`：LeakyReLU 的负斜率参数

---

**示例计算**

假设：$fan_{in} = 256$

计算过程：

- $gain = \sqrt{\frac{2}{1 + a²}}$

- 当 a = √5 时， $gain = \sqrt{\frac{2}{1 + 5}} = \sqrt{\frac{1}{3}}$

- 接着计算标准差：$\text{std} = \frac{\text{gain}}{\sqrt{fan_{in}}} = \frac{\sqrt{1/3}}{\sqrt{256}}$

- 最后得到均匀分布范围：$bound = \sqrt{3} × std$

- 因此：
    $$
    w \sim \mathcal{U}(-\text{bound}, \text{bound})
    $$

---

**Kaiming Uniform 分布总结**

| 名称     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 分布类型 | 均匀分布（Uniform）                                          |
| 范围     | $\left[-\text{gain} \cdot \sqrt{\frac{3}{\text{fan}}}, \text{gain} \cdot \sqrt{\frac{3}{\text{fan}}}\right]$ |
| 默认参数 | `a=0, mode='fan_in', nonlinearity='leaky_relu'`              |
| 应用场景 | Linear、Conv 等网络层初始化，适合 ReLU / LeakyReLU           |

#### 1.3 Xavier_Uniform_ 初始化

Xavier 初始化是另一种常见权重初始化方式。

**分布公式**
$$
w \sim \mathcal{U}(-\text{limit}, \text{limit})
$$

其中：$\text{limit} = \sqrt{\frac{6}{\text{fan\_in} + \text{fan\_out}}}$

**参数说明**

- `fan_in`：输入神经元数量
- `fan_out`：输出神经元数量

---

**示例计算**

假设：

- 输入层：784
- 隐藏层：300

则：

$\text{fan\_in} + \text{fan\_out} = 784 + 300 = 1084$

$\text{limit} = \sqrt{\frac{6}{1084}}$

最终：

$$
w \sim \mathcal{U}\left(-\sqrt{\frac{6}{\text{fan\_in}+\text{fan\_out}}}, \sqrt{\frac{6}{\text{fan\_in}+\text{fan\_out}}}\right)
$$

***

**适用场景**

Xavier 初始化通常适用于：

- **tanh**
- **sigmoid**

### 2. 对象名()

在 Python 中，`对象名()` 这种写法表示**“调用”**该对象。

简单来说，它的含义是：“让这个对象执行它所定义的动作”。

**核心解释：**

在 Python 中，函数和类都是“对象”。

1.  **如果对象是一个函数**：`对象名()` 就是**执行该函数**内部的代码。
2.  **如果对象是一个类**：`对象名()` 就是**创建该类的一个实例**（也就是实例化对象）。
3.  **如果对象是一个普通的实例**：只有当这个类定义了 `__call__` 方法时，`实例名()` 才能执行，否则会报错。

**底层原理：**
当你在对象后面加上 `()` 时，Python 实际上是在调用该对象的 `__call__` 方法。

---

**简单示例**

**情况一：对象是函数（最常见）**

这是最直观的用法，表示执行函数。

```python
# 定义一个函数对象，名字叫 greet
def greet():
    print("你好，世界！")

# 此时 greet 是一个对象（函数对象）
print(type(greet))  # 输出：<class 'function'>

# 使用 greet() 调用它
greet()  # 输出：你好，世界！
```

**情况二：对象是类**

这种写法用于创建一个新的对象实例。

```python
# 定义一个类，名字叫 Dog
class Dog:
    def __init__(self):
        print("一只小狗被创建出来了！")

# 使用 Dog() 调用类
my_dog = Dog()  # 输出：一只小狗被创建出来了！
```

**情况三：对象是实例（进阶用法）**

普通的实例后面加 `()` 会报错，除非这个类实现了 `__call__` 方法。这让对象可以像函数一样被调用。

```python
class Multiplier:
    def __init__(self, factor):
        self.factor = factor
    
    # 定义 __call__ 方法，让实例可以像函数一样被调用
    def __call__(self, number):
        return number * self.factor

# 创建一个对象，乘数设为 5
times_five = Multiplier(5)

# times_five 是一个实例对象，但我们可以在它后面加 ()
# 这就是“对象名()”的第三种情况
result = times_five(10) 

print(result)  # 输出：50
```

### 3. 图像任务归一化、标准化 torchvision.transforms

在 **torchvision.transforms** 中，归一化与标准化主要通过几个常用的 **transform** 完成，通常用于数据预处理，并在 `Dataset` 或 `DataLoader` 读取数据时执行。

#### 3.1 归一化`transforms.ToTensor()`

将图像转换为 **PyTorch Tensor**，并自动完成一次简单归一化。

基本语法：==`transforms.ToTensor()`==

作用：

- 将 **PIL Image 或 numpy.ndarray** 转换为 **Tensor**
- **转换数据类型**：数据类型变为 `float32`，因为 PyTorch 的神经网络层通常处理浮点数数据
- **缩放像素值**：像素值从 **[0,255] → [0,1]**，这是通过将每个像素值除以 255 来实现的。
- **增加通道维度**：对于单通道的灰度图像，它会增加一个通道维度，使其成为具有两个维度的张量，即 **[channels, height, width]**。对于三通道的彩色图像，它将保持三个通道。

---

#### 3.2 标准化`transforms.Normalize()`

用于对 **图像张量的每个通道进行标准化**。将数据的分布调整为均值为 0，标准差为 1 的分布，从而减少了不同特征之间的尺度差异，有助于模型更快地收敛，并且对学习率的选择更为鲁棒。

基本语法：==`transforms.Normalize(mean, std, inplace=False)`==

- `mean`

    - 类型：`sequence`

    - 含义：每个 **通道的均值**

    - 例如 RGB 图像：

        ```python
        mean = [0.5, 0.5, 0.5]
        ```

        表示：R通道均值 = 0.5，G通道均值 = 0.5，B通道均值 = 0.5

-  `std`

    - 类型：`sequence`
    - 含义：每个 **通道的标准差**

- `inplace`

    - 类型：`bool`
    - 默认：`False`
    - 含义：
        - `False`：返回新的 Tensor
        - `True`：直接在原 Tensor 上修改

**计算方式**

`Normalize` 实际执行：

```
output = (input - mean) / std
```

并且是 **按通道计算**：

```
R = (R - mean_R) / std_R
G = (G - mean_G) / std_G
B = (B - mean_B) / std_B
```

---

#### 3.3 `transforms.Compose()`

用于 **组合多个 transform**。

基本语法：==`transforms.Compose(transforms_list)`==

参数:`transforms_list`

- 类型：`list`
- 含义：需要按顺序执行的 transform

------

#### 3.4 完整示例

```python
from torchvision import transforms

transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize(
        mean=[0.5,0.5,0.5],
        std=[0.5,0.5,0.5]
    )
])

img_tensor = transform(img)
```

执行流程：

```
PIL Image
   ↓
ToTensor()      # 转Tensor并缩放到[0,1]
   ↓
Normalize()     # 标准化
   ↓
Tensor(C,H,W)
```

#### 4. 早停（Early Stopping）

**早停**是一种正则化技术，用于**避免过拟合**。原理是：

- 在训练过程中持续监控验证集指标（如验证损失或验证准确率）
- 当验证指标不再改善时，提前停止训练
- 保存验证指标最佳时的模型，避免继续训练导致过拟合

---

**主要参数说明**

1. **min_delta**（最小变化阈值）

- **含义**：将一次变化视为“改进”的最小阈值
- **作用**：如果验证指标的绝对变化小于 `min_delta`，则不视为改进
- **示例**：`min_delta=0.001` 时，验证损失从 0.5 变为 0.5005（变化 0.0005 < 0.001）不算改进

2. **Patience**（耐心值）

- **含义**：允许验证指标不改善的轮数（epochs）
- **作用**：连续 `Patience` 个 epoch 无改进后停止训练
- **示例**：`patience=5` 时，连续 5 个 epoch 无改进则停止

---

**工作原理示例**

假设 `patience=3`，`min_delta=0.001`：

- Epoch 1-5：验证损失持续下降 → 继续训练
- Epoch 6-8：验证损失变化 < 0.001 或上升 → 开始计数
- Epoch 9：连续 3 个 epoch 无改进 → 触发早停，保存 Epoch 5 的模型

这样可以防止模型在训练集上过度拟合，同时节省训练时间。

### 5. 模型保存（ModelCheckpoint）

**为什么需要保存模型？**

1. 为了上线部署

- 训练好的模型需要保存下来，用于生产环境的推理
- 避免每次使用模型都需要重新训练

2. 避免训练中断导致的数据丢失

- 训练过程可能因为各种原因中断（断电、程序崩溃、服务器故障等）
- 保存模型后，可以从上次的保存点继续训练，而不是从头开始
- 节省训练时间和计算资源

---

**PyTorch模型保存的核心接口**

#### 5.1 `torch.save()` - 保存模型

**基本语法：**==`torch.save(obj, f)`==

**功能**：将对象保存到文件

**参数**：

- `obj`: 要保存的对象（通常是字典，包含模型状态、优化器状态等）
- `f`: 文件路径（字符串或文件对象）

**示例**：

```python

    'epoch': epoch,
    'loss': loss,

torch.save(save_info, 'checkpoint.pth')
```

**基本语法：**==`torch.load(f, map_location=None)`==

**功能**：从文件加载对象

**参数**：

- `f`: 文件路径
- `map_location`: 指定加载到哪个设备（CPU/GPU），例如 `'cpu'` 或 `'cuda:0'`

**示例**：

```python

```

#### 5.3 `model.state_dict()` - 获取模型状态字典

**基本语法：**==`model.state_dict()`==

**功能**：返回模型的所有参数（权重和偏置）的字典

**返回**：`OrderedDict`，键为层名称，值为参数张量

**示例**：

- `strict`: 是否严格匹配（默认True），如果为False，允许部分匹配

### 7. nn.Sequential() 按顺序构建神经网络层

`nn.Sequential()` 是 PyTorch 中用于**按顺序构建神经网络层的容器**。它可以把多个网络层按照给定顺序组合成一个整体模型，并在前向传播时**自动按顺序依次执行每一层**。

#### 7.1 基本作用

`nn.Sequential()` 的作用是：

- **顺序组合多个网络层**
- **自动完成前向传播流程**
- **减少手写 `forward()` 的代码**

当输入数据进入模型时，数据会：

​	输入 → 第1层 → 第2层 → 第3层 → ... → 输出

**每一层的输出会自动作为下一层的输入**

#### 7.2 基本语法

```python
nn.Sequential(
    层1,
    层2,
    层3,
    ...
)
```

例如：

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(10, 20),
    nn.ReLU(),
    nn.Linear(20, 1)
)
```

网络结构为：

```python
输入(10)
   ↓
Linear(10 → 20)
   ↓
ReLU
   ↓
Linear(20 → 1)
   ↓
输出
```

#### 7.3 前向传播过程

如果输入：

```python
x = torch.randn(5, 10)
y = model(x)
```

执行顺序为：

```python
x
↓
Linear(10,20)
↓
ReLU()
↓
Linear(20,1)
↓
y
```

即：
$$
y = Linear_2(ReLU(Linear_1(x)))
$$
整个过程 **自动完成，不需要自己写 `forward()`**。

#### 7.4 三种创建方式

**写法1：直接传入层（最常用）**

```python
model = nn.Sequential(
    nn.Linear(10,20),
    nn.ReLU(),
    nn.Linear(20,1)
)
```

------

**写法2：使用 `OrderedDict`指定层名称**

```python
from collections import OrderedDict

model = nn.Sequential(OrderedDict([
    ("fc1", nn.Linear(10,20)),
    ("relu", nn.ReLU()),
    ("fc2", nn.Linear(20,1))
]))
```

------

**写法3：先创建再添加（动态构建）**

```python
model = nn.Sequential()

model.add_module("fc1", nn.Linear(10,20))
model.add_module("relu", nn.ReLU())
model.add_module("fc2", nn.Linear(20,1))
```

特点：

- 可以动态生成网络
- 适合循环添加

#### 7.5 与普通模型的区别

不用 `Sequential` 时，需要自己写 `forward()`：

```python
class Net(nn.Module):

    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(10, 20)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(20, 1)

    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x
```

使用 `Sequential`：

```python
model = nn.Sequential(
    nn.Linear(10,20),
    nn.ReLU(),
    nn.Linear(20,1)
)
```

**Net类方式：**

- 可以在 forward 中添加条件判断、循环、分支等复杂逻辑

- 可以访问中间层的输出用于其他用途

**Sequential方式：**

- 只能按顺序执行，适合简单的线性堆叠

- 无法在中间添加复杂逻辑

---

**两种方式结合示例**

```python
from torch import nn

class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()  # 展平输入，[batch, 1, 28, 28] -> [batch, 28*28]
        
        # 先初始化 Sequential
        self.network = nn.Sequential()
        
        # 第1层：784 -> 100
        self.network.add_module('fc1', nn.Linear(28*28, 100))
        self.network.add_module('relu1', nn.ReLU())
        
        # 使用循环动态添加网络层
        # 中间18层，每层都是100 -> 100
        for i in range(18):
            self.network.add_module(f'fc{i+2}', nn.Linear(100, 100))
            self.network.add_module(f'relu{i+2}', nn.ReLU())
        
        # 输出层：100 -> 10（不需要激活函数）
        self.network.add_module('fc20', nn.Linear(100, 10))

    # 前向传播方法，调用 model(x) 会自动调用 forward(x)
    def forward(self, x):
        x = self.flatten(x)  # 展平输入
        x = self.network(x)  # 自动按顺序依次执行每一层
        return x
```

### 8. 反向传播

**反向传播（Backpropagation，BP）是神经网络训练时用来计算各层参数梯度并更新权重**的一种算法。

它的核心作用是：**根据模型预测误差，反向计算每一层参数对误差的影响，从而指导参数更新。**

可以把神经网络训练理解为两个阶段：**前向传播 + 反向传播**。

#### 8.1 前向传播（Forward Propagation）

在前向传播中，数据从输入层开始，依次经过各层神经元计算，最终得到模型的预测结果。

例如一个简单神经网络：

```
输入层 → 隐藏层 → 输出层
```

每一层神经元都会进行如下计算：
$$
z = wx + b
$$
再经过激活函数：
$$
a = f(z)
$$
最终得到预测值：
$$
\hat{y}
$$
然后利用真实值 $y$ 与预测值 $\hat{y}$ 计算**损失函数（Loss）**：
$$
Loss = L(y,\hat{y})
$$
损失函数表示模型预测的误差大小。

#### 8.2 反向传播（Backpropagation）

反向传播的任务是：
 **根据损失函数，计算每一个参数的梯度。**

也就是计算：
$$
\frac{\partial Loss}{\partial w}
$$
表示：
 **权重改变一点点，Loss 会变化多少。**

如果梯度为：

- 正数 → 权重应该减小
- 负数 → 权重应该增大

因此可以用梯度下降更新参数：
$$
w = w - \eta \frac{\partial Loss}{\partial w}
$$
其中：

- $w$：权重
- $\eta$：学习率
- $\frac{\partial Loss}{\partial w}$：梯度

------

**为什么叫“反向”传播**

因为梯度的计算顺序是：

```
输出层 → 隐藏层 → 输入层
```

也就是 **从网络最后一层向前计算**。

原因是梯度计算依赖**链式法则**：
$$
\frac{\partial Loss}{\partial w_1}
=
\frac{\partial Loss}{\partial z_2}
\cdot
\frac{\partial z_2}{\partial z_1}
\cdot
\frac{\partial z_1}{\partial w_1}
$$
也就是说：

**前一层的梯度依赖后一层的梯度。**

因此必须从 **输出层开始逐层往回算**。

------

**简单直观理解**

可以把反向传播理解成：

1️⃣ 神经网络先做一次预测（前向传播）
2️⃣ 计算预测误差（Loss）
3️⃣ 从最后一层开始计算误差对参数的影响
4️⃣ 把误差信息逐层向前传递
5️⃣ 得到所有参数的梯度
6️⃣ 用梯度下降更新参数

#### 8.3 在 PyTorch 中的实现

PyTorch 已经自动实现了反向传播（自动求导）。

典型训练代码：

```python
import torch
import torch.nn as nn

model = nn.Linear(10, 1)
criterion = nn.MSELoss()

x = torch.randn(5, 10)
y = torch.randn(5, 1)

# 前向传播
y_pred = model(x)

# 计算损失
loss = criterion(y_pred, y)

# 反向传播
loss.backward()
```

其中：

```python
loss.backward()
```

这一步就是 **自动进行反向传播计算梯度**。

梯度会保存在：

```python
param.grad
```

然后优化器更新参数：

```python
optimizer.step()
```

#### 8.4 为什么前向传播和反向传播要交替进行

- 反向传播必须依赖前向传播得到的损失值。
- 参数更新后模型已经改变，需要重新进行前向传播。
- 训练过程本质上是不断重复“预测—修正”的循环。

因此神经网络训练实际上是一个持续迭代的过程：

```
预测 → 计算误差 → 反向修正 → 再预测
```

通过不断交替执行前向传播和反向传播，模型的参数会逐渐优化，最终使预测误差不断减小。

#### 8.5 为什么要清空梯度

清空梯度的原因是 **PyTorch 的梯度默认会累积**。

当执行：

```python
loss.backward()
```

时，PyTorch 会计算梯度，并把结果**加到 `param.grad` 中**。

注意这里是：

```python
grad = grad + 新梯度
```

而不是：

```python
grad = 新梯度
```

这就叫 **梯度累积（gradient accumulation）**。

如果不清空梯度：

- 新梯度会和旧梯度相加
- 导致参数更新错误
- 影响模型训练效果

因此每一轮训练通常需要：

```python
optimizer.zero_grad()
```

来清除旧梯度，然后再执行：

```python
loss.backward()
```

计算新的梯度。
