#### 1.6 张量的形状操作

*   `reshape()`: 调整形状
*   `transpose()`: 交换两个维度
*   `permute()`: 重新排列多个维度
*   `unsqueeze()`: 在指定维度上增加1个维度
*   `squeeze()`: 删除大小为1的维度
*   `view()`: 调整张量的形状，需要连续内存
*   `is_contiguous()`: 判断是否内存连续
*   `contiguous()`: 转换为连续内存

```python
import torch

x = torch.randn(2, 3, 4)
print(x.shape)
print(x.size())         # size() 方法和 shape 一样, 返回张量的形状

# 1. 调整形状
x = x.reshape(2, 12)            # 调整为2行12列
print("x.shape1:",x.shape)
x = x.reshape(-1, 3)            # 不限制行数, 列数调整为3列 (会自动计算行数)
print("x.shape2:",x.shape)

# 2. 交换维度
x = torch.randn(2, 3, 4)
x = x.transpose(1, 2)
print(x.shape)

# 3. 重新排列多个维度
# 第3维度变为第1维, 第2维变为第2维, 第1维变为第3维
x = x.permute(2,1,0)
print(x.shape)

# 4. 在指定维度上增加一个维度, 会添加形状为1的维度
x = x.unsqueeze(dim = 2)
print(x.shape)

# 5. 在指定维度上删除一个维度, 会删除形状为1的维度 (如果该维度不存在形状为1的维度, 则返回原张量)
x = x.squeeze(dim = 1)
print(x.shape)

# 6. 调整形状, 需要连续内存
# 经过升维和降维操作, 张量的数据存储位置 (内存) 可能会改变, 所以内存可能不连续
# 使用view方法, 如果内存不连续, 那么会报错
# x = x.view(3,-1)
# print(x)

# 6. 判断是否是连续内存
print(x.is_contiguous())

# 7. 转换为连续内存
x = x.contiguous()
print(x.is_contiguous())

# 8. 调整形状, 需要连续内存
x = x.view(3,-1)

```

#### 1.7 张量的拼接操作

*   `cat()`: 张量拼接，按已有维度拼接。除拼接维度外，其他维度大小须相同
*   `stack()`: 张量堆叠，按新维度堆叠。所有张量形状必须一致


### 2. 自动微分

训练神经网络时，最常用的算法就是反向传播。

在该算法中，参数（模型权重）会根据损失函数关于对应的参数的梯度进行调整。为了计算这些梯度，Pytorch内置了自动微分模块，具体来说就是名为 `torch.autograd` 的自动微分引擎，他支持任意计算图（计算图就是构建好的神经网络）的自动梯度计算：

![image-20260306021829265](https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260306021829380.png)

如何理解自动微分呢？大白话来说，其实就是**自动求梯度**

举个例子（以线性回归为例，如上图所示）

*   假设模型参数是：$y = w \cdot x + b$
*   现在提供了特征值x，目标值y
*   初始化随机 权重w和偏置b
*   通过模型 $y' = w \cdot x + b$ 可以得到拟合结果
*   然后对拟合结果与真实结果求得损失函数
*   接下来利用损失函数，对w和b求偏导，得到梯度下降的梯度

$$
w_n = w_{n-1} - \eta \frac{\partial Loss}{\partial w}
$$

$$
b_n = b_{n-1} - \eta \frac{\partial Loss}{\partial b}
$$



*   然后更新w和b，重新拟合

而自动微分模块，其实就是根据损失函数Loss自动求得权重w和偏置b的梯度。

接下来我们使用这个结构进行自动微分模块的介绍。我们使用 `backward()` 方法实现梯度的计算，`grad` 属性来访问梯度

```python
import torch

# 1. 准备数据：参数与目标值
x = torch.tensor(5) #特征
y = torch.tensor(0.)

# 2. 初始化参数：权重与偏置
w = torch.tensor(1., requires_grad=True, dtype=torch.float32)
b = torch.tensor(3., requires_grad=True, dtype=torch.float32)

# 3. 构建神经网络并输出值
z = w * x + b

# 4. 计算损失
loss = torch.nn.MSELoss()
loss = loss(z, y)

# 5. 反向传播，自动微分，计算梯度
loss.backward()

# 6. 访问梯度
print(w.grad)
print(b.grad)
```

```python
import torch

# 1. 准备数据：参数与目标值
x = torch.ones(2,5)
y = torch.zeros(2,3)

# 2. 初始化参数：权重与偏置
w = torch.randn(5,3, requires_grad=True)
b = torch.randn(3,requires_grad=True,)

# 3. 构建神经网络并输出值
z = torch.matmul(x, w) + b

# 4. 计算损失
loss = torch.nn.MSELoss()
loss = loss(z, y)

# 5. 反向传播，自动微分，计算梯度
loss.backward()

# 6. 访问梯度
print(w.grad)
print(b.grad)
```

### 3. PyTorch 训练模型一般步骤

通过 **PyTorch** 训练一个模型一般可以分为以下 4 个步骤：

**1. 准备数据**

- 自定义 `Dataset` 类
    - 实现`__init__(self)`：加载原始数据，保存数据处理需要的配置
    - 实现 `__getitem__(index)`：根据索引返回对应位置的样本数据
    - 实现 `__len__()`：返回数据集的总样本数
- 使用 `DataLoader` 加载数据
    - 设置 `batch_size`：按批次读取数据
    - 设置 `shuffle=True`：打乱样本顺序，避免模型陷入局部最优

**2. 构建模型**

- 使用 `torch.nn.Module` 搭建神经网络结构
- 在 `forward()` 方法中定义前向计算过程

**3. 定义损失函数与优化器**

- 选择损失函数（如：均方误差 `MSELoss`）用于衡量预测值与真实值的差距
- 选择优化器（如：`SGD`、`Adam`）用于更新模型参数

**4. 模型训练**

- 使用两层循环进行训练
    - 外层：`epoch`（训练轮数）
    - 内层：`step`（每个 batch 的训练次数）
        - `step ≈ 样本总数 / batch_size`
- 每个 step 的训练流程：
    1. 前向计算（`model(x)`）
    2. 计算损失（`loss`）
    3. 清空梯度（`optimizer.zero_grad()`）
    4. 反向传播求梯度（`loss.backward()`）
    5. 更新参数（`optimizer.step()`）

### 4. Dataset 和 DataLoader

一般案例中，送入模型中的是DataLoader中的一批一批的数据，而DataLoader中的数据是从Dataset数据集中获取的。在很多任务中，Dataset数据集已经有别的组织或者框架给我们封装好了，但是也有可能没有给我们封装好，有的时候我们也需要自己从原始数据封装为Dataset供模型训练。

#### 4.1 Dataset

Dataset是Pytorch中的一个抽象类，用于表示数据集。它**允许用户自定义数据集的接口，使得用户可以使用统一的形式来访问数据**。

举个例子：

*   Dataset就像“整理好的快递箱”
*   每个快递箱（Dataset）里装着多个包裹（样本）
*   每个包裹上贴了编号（索引）
*   快递员（DataLoader）能按编号快速找到并取出包裹，不用翻遍整个箱子

**定义方法：**

PyTorch 要求自定义Dataset必须继承 `torch.utils.data.Dataset`，并实现 **3 个核心方法** —— 这 3 个方法就是“数据容器的说明书”，告诉框架“数据有多少、怎么取”。

*   `__init__(self)`：加载原始数据，保存数据处理需要的配置，如样本的大小，总个数等。相当于“把所有包裹装进快递箱”
*   `__len__(self)`：作用是告诉框架，容器中有多少个样本，返回总样本个数即可
*   `__getitem__(self, index)`：通过数据的索引，获取样本。

```python
# 自定义Dataset
import torch
from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self):
        # 1. 初始化数据，例如读取文件
        self.data = ['李云龙','楚云飞','赵刚','丁伟','孔捷','常乃超','魏大勇','秀芹']
        self.total = len(self.data)

    def __getitem__(self, index):
        # 2. 获取索引对应的数据
        return self.data[index]


    def __len__(self):
        # 3. 返回数据集的长度
        return self.total

if __name__ == '__main__':
    dataset = MyDataset()
    print(dataset[1])
```

#### 4.2 DataLoader

DataLoader是 PyTorch 中用于批量加载数据的工具。
它允许用户根据自定义的Dataset对象创建一个数据加载器，用于**批量加载和处理数据**。
DataLoader可以**按照批次大小对数据集进行分割**，并**提供多线程数据加载和预取功能**。

```python
# DataLoader的创建
import torch
from torch.utils.data import DataLoader

# 创建DataLoader
# batch_size: 每次批次的大小（一般是2的倍数）
# shuffle: 是否打乱数据
dataloader = DataLoader(MyDataset(), batch_size=2, shuffle=False)
	# 每次取两个样本（Tensor）装箱，打包成一个data（Tensor）
    # 此处示例使用的是列表而非Tensor，所以返回data的类型也是list而不是Tensor

# 获取批次数据
for data in dataloader:
    print(data)
```

### 1. 人工神经网络（Artificial Neural Network，简写为ANN）

简称神经网络（NN）

来源不同树突（树突都会有不同的权重）的信息，进行加权计算，输入到细胞中做加和，再通过激活函数输出细胞值。

> **`nn.Linear()`全连接神经网络**：第 N 层的每个神经元和第 N-1层 的所有神经元相连
>
> 每一个神经元都相当于做一次**逻辑回归**（线性回归＋激活函 数）【也存在做其他处理的】

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307011116329.png" alt="image-20260307011116205" style="zoom:67%;" />

神经网络中信息只向一个方向移动，即从输入节点向前移动，通过隐藏节点，再向输出节点移动。每个连接都有一个权重值。

其中的基本部分是:

1. **输入层**: 即输入 x 的那一层（x 即**特征**）
2. **输出层**: 即输出 y 的那一层（y 即**标签**）
3. **隐藏层**: 输入层和输出层之间都是隐藏层

![image-20260307011257281](https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307011257368.png)

每一个神经元工作时，**前向传播**会产生两个值，**内部状态值**和**激活值**；**反向传播**时会产生**激活值梯度**和**内部状态值梯度**。

通过控制每个神经元的内部状态值、激活值的大小；每一层的内部状态值的方差、每一层的激活值的方差可让整个神经网络工作的更好。

### 2. 常见激活函数

#### 2.1 sigmoid 激活函数

激活函数公式：

$$
f(x) = \frac{1}{1 + e^{-x}}
$$
激活函数求导公式：

$$
f'(x) = (\frac{1}{1+e^{-x}})' = \frac{1}{1+e^{-x}}(1 - \frac{1}{1+e^{-x}}) = f(x)(1 - f(x))
$$
sigmoid 激活函数的函数图像如下:

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307012559282.png" alt="image-20260307012559177" style="zoom:67%;" />

从 sigmoid 函数图像可以得到，sigmoid 函数可以**将任意的输入映射到 (0, 1) 之间**，当输入的值大致在 <-6 或者 >6 时，意味着输入任何值得到的激活值都是差不多的，这样会丢失部分的信息。比如：输入 100 和输出 10000 经过 sigmoid 的激活值几乎都是等于 1 的，但是输入的数据之间相差 100 倍的信息就丢失了。

对于 sigmoid 函数而言，输入值在 **[-6, 6]** 之间输出值才会有**明显差异**，输入值在 **[-3, 3]** 之间才会有**比较好的效果**。

通过上述导数图像，我们发现**导数数值范围是 (0, 0.25)**，当输入 <-6 或者 >6 时，sigmoid 激活函数图像的**导数接近为 0**，此时**网络参数将更新极其缓慢，或者无法更新**。

一般来说，sigmoid 网络在 **5 层之内**就会产生**梯度消失**现象。而且，该激活函数并不是以 0 为中心的，所以在实践中这种激活函数使用的很少。sigmoid函数一般只用于==二分类的输出层==。

#### 2.2 tanh 激活函数

Tanh 叫做双曲正切函数，其公式如下：

$$
f(x) = \frac{1 - e^{-2x}}{1 + e^{-2x}}
$$
激活函数求导公式:

$$
f'(x) = (\frac{1-e^{-2x}}{1+e^{-2x}})' = 1 - f^2(x)
$$
Tanh 的函数图像、导数图像如下：

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307012843287.png" alt="image-20260307012843183" style="zoom:67%;" />

由上面的函数图像可以看到，Tanh 函数**将输入映射到 (-1, 1) 之间**，**图像以 0 为中心**，在 0 点对称，当输入 大概<-3 或者 >3 时将被映射为 -1 或者 1。其**导数值范围 (0, 1)**，当输入的值大概 <-3 或者 > 3 时，其导数近似 0。

与 Sigmoid 相比，它是以 0 为中心的，使得其**收敛速度要比 Sigmoid 快**，减少迭代次数。然而，从图中可以看出，Tanh 两侧的导数也为 0，同样会造成**梯度消失**。

若使用时可**在==隐藏层==使用tanh函数，在输出层使用sigmoid函数**。

#### 2.3 ReLU 激活函数

ReLU 激活函数公式如下：

$$
f(x) = \max(0, x)
$$
激活函数求导公式:

$$
f'(x) = 0\text{或}1
$$
函数图像如下:

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307013033081.png" alt="image-20260307013032976" style="zoom:67%;" />

从上述函数图像可知，ReLU 激活函数**将小于 0 的值映射为 0，而大于 0 的值则保持不变**，它**更加重视正信号，而忽略负信号**，这种激活函数运算更为简单，能够提高模型的训练效率。

但是，如果我们网络的参数采用随机初始化时，很多参数可能为负数，这就使得输入的负值会被舍去，而输入的正值则会保留，这可能在大部分的情况下并不是我们想要的结果。

ReLU 的导数图像如下:

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307013125528.png" alt="image-20260307013125433" style="zoom:67%;" />

ReLU是目前最常用的激活函数。从图中可以看到，当x<0时，ReLU导数为0，而当x>0时，则不存在饱和问题。所以，**ReLU 能够在x>0时保持梯度不衰减，从而缓解梯度消失问题**。然而，随着训练的推进，部分输入会落入小于0区域，导致对应权重无法更新。这种现象被称为**“神经元死亡”**。

与sigmoid相比，RELU的优势是：

*   采用sigmoid函数，计算量大（指数运算），反向传播求误差梯度时，求导涉及除法，计算量相对大，而采用Relu激活函数，整个过程的计算量节省很多。
*   sigmoid函数反向传播时，很容易就会出现梯度消失的情况，从而无法完成深层网络的训练。
*   Relu会使一部分神经元的输出为0，这样就造成了网络的稀疏性，并且减少了参数的相互依存关系，**缓解了过拟合问题的发生**。

#### 2.4 SoftMax

softmax用于多分类过程中，它是二分类函数sigmoid在**多分类**上的推广，目的是**将多分类的结果以概率的形式展现出来**。

计算方法如下图所示：

$$
softmax(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$
**整体作用:** 将分子除以总和，实现**归一化（Normalization）**，确保所有输出值的和等于 1

Softmax 直白来说就是将网络输出的 logits 通过 softmax 函数，就**映射成为(0,1)的值**，而这些值的**累和为1**（满足概率的性质），那么我们将它理解成概率，**选取概率最大（也就是值对应最大的）节点，作为我们的预测目标类别**。

#### 2.5 激活函数选择

对于**隐藏层**:

1.  优先选择ReLU激活函数
2.  如果ReLu效果不好，那么尝试其他激活，如Leaky ReLu等。
3.  如果你使用了ReLU，需要注意一下Dead ReLU问题，避免出现大的梯度从而导致过多的神经元死亡。
4.  少用使用sigmoid激活函数，可以尝试使用tanh激活函数
5.  **如果权重初始化采用Xavier初始化，可以选用tanh激活函数或sigmoid激活函数**
6.  **如果权重初始化采用kaiming初始化，可以选用relu激活函数**

对于**输出层**:

1.  二分类问题选择sigmoid激活函数
2.  多分类问题选择softmax激活函数
3.  回归问题选择identity激活函数

### 3. 交叉熵损失和均方误差损失对比分析（使用SoftMax） 

**均方误差(回归)公式**
$$
MSE = \frac{1}{n}\sum_{i}^{n}(\hat{y}_i - y_i)^2
$$
**交叉熵损失公式**
$$
L = \frac{1}{N}\sum_{i}L_i = -\frac{1}{N}\sum_{i}\sum_{c=1}^{M}y_{ic}\log(p_{ic})
$$
**均方误差与交叉熵损失对比：**

- **相同点：**当输出值与真实值接近的话，cross_entropy 和 rmse 的值都会接近 0
- **cross_entropy 具有 rmse 不具有的优点：**避免学习速率降低的情况。(注意这种效果仅限于输出层，隐藏层的学习速率与其使用的激活函数密切相关。)
- 主要原因是**逻辑回归配合 MSE 损失函数时，采用梯度下降进行学习时，会出现模型一开始训练时，学习速率非常慢的情况（MSE 损失函数）**

- **均方损失：**假设误差是正态分布，适用于**线性的输出(如回归问题)**，特点是对于与真实结果差别越大，则惩罚力度越大，这并不适用于分类问题
- **交叉熵损失：**假设误差是二值分布，可以视为预测概率分布和真实概率分布的相似程度。在**分类问题**中有良好的应用。

> 对于更小的概率，-log所得值越大（且增大的越快），那么预测错误时，1会乘上一个较小概率的log，使得对于该样本的损失值变得极大

结论：**交叉熵损失 更能捕捉到预测效果的差异，交叉熵损失相对于均分误差损失梯度更大，能够让模型更快收敛！**

### 4. **数据集为什么要划分为训练集、验证集、测试集**

**1. 训练集（Training Set）**
用于**训练模型参数**，让模型学习数据中的规律。

**2. 验证集（Validation Set）**
用于**调节超参数和选择模型**，并判断是否出现**过拟合**。

**3. 测试集（Test Set）**
用于**最终评估模型性能**，检验模型在**未知数据上的泛化能力**。
在最终评估前，测试集的信息是完全没有被模型获取过的。

**核心原因：**

- 避免模型只记住训练数据（过拟合）
- 保证模型评估结果**客观可靠**

**常见划分比例：**

- 训练集：60%~80%
- 验证集：10%~20%
- 测试集：10%~20%

**一句话总结：**

> **<span style='color:red'>为了防止人工调参造成的测试集的信息泄露</span>**

### 5. `nn.Linear()` 全连接神经网络

**第 N 层的每个神经元都与第 N−1 层的所有神经元相连**，因此称为**全连接层（Fully Connected Layer）**。

每个神经元的计算本质是一个**线性变换**：
$$
y = wx + b
$$
其中：

- $x$：输入特征
- $w$：权重矩阵
- $b$：偏置
- $y$：输出结果

如果在线性变换之后再接**激活函数**（如 ReLU、Sigmoid 等），就形成了一个完整的神经元计算过程，因此可以理解为：

> 每一个神经元都相当于做一次 **逻辑回归（线性变换 + 激活函数）**

在 PyTorch 中使用 `nn.Linear()` 来实现该层，因此也称为：

- **线性层（Linear Layer）**
- **全连接层（Fully Connected Layer）**

------

**输入数据要求**

`nn.Linear()` 只支持 **二维 Tensor** 输入，即 shape = (样本数batch_size, 特征数feature)

------

**高维数据的处理**

对于图像等高维数据（如 `(batch, channel, height, width)`），
在进入线性层之前需要先展开为一维向量，因此通常需要使用`nn.Flatten()`展开层

作用：

```
(batch, channel, height, width)
          ↓
(batch, channel × height × width)
```

即把多维特征**展开为一维特征向量**，才能输入到 `nn.Linear()`。

**简单示例**

```python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Flatten(),        # 展平
    nn.Linear(784, 128), # 全连接层
    nn.ReLU(),           # 激活函数
    nn.Linear(128, 10)
)
```

> 这里表示：784维输入 → 128个神经元 → 10维输出
