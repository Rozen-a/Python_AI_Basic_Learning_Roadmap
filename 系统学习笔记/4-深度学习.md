#### 1.6 张量的形状操作

*   `reshape()`: 调整形状
*   `transpose()`: 交换两个维度
*   `permute()`: 重新排列多个维度
*   `unsqueeze()`: 在指定维度上增加1个维度
*   `squeeze()`: 删除大小为1的维度
*   `view()`: 调整张量的形状，需要连续内存
*   `is_contiguous()`: 判断是否内存连续
*   `contiguous()`: 转换为连续内存

```python
import torch

x = torch.randn(2, 3, 4)
print(x.shape)
print(x.size())         # size() 方法和 shape 一样, 返回张量的形状

# 1. 调整形状
x = x.reshape(2, 12)            # 调整为2行12列
print("x.shape1:",x.shape)
x = x.reshape(-1, 3)            # 不限制行数, 列数调整为3列 (会自动计算行数)
print("x.shape2:",x.shape)

# 2. 交换维度
x = torch.randn(2, 3, 4)
x = x.transpose(1, 2)
print(x.shape)

# 3. 重新排列多个维度
# 第3维度变为第1维, 第2维变为第2维, 第1维变为第3维
x = x.permute(2,1,0)
print(x.shape)

# 4. 在指定维度上增加一个维度, 会添加形状为1的维度
x = x.unsqueeze(dim = 2)
print(x.shape)

# 5. 在指定维度上删除一个维度, 会删除形状为1的维度 (如果该维度不存在形状为1的维度, 则返回原张量)
x = x.squeeze(dim = 1)
print(x.shape)

# 6. 调整形状, 需要连续内存
# 经过升维和降维操作, 张量的数据存储位置 (内存) 可能会改变, 所以内存可能不连续
# 使用view方法, 如果内存不连续, 那么会报错
# x = x.view(3,-1)
# print(x)

# 6. 判断是否是连续内存
print(x.is_contiguous())

# 7. 转换为连续内存
x = x.contiguous()

# 8. 调整形状, 需要连续内存
```

#### 1.7 张量的拼接操作

*   `cat()`: 张量拼接，按已有维度拼接。除拼接维度外，其他维度大小须相同

### 2. 自动微分

训练神经网络时，最常用的算法就是反向传播。

在该算法中，参数（模型权重）会根据损失函数关于对应的参数的梯度进行调整。为了计算这些梯度，Pytorch内置了自动微分模块，具体来说就是名为 `torch.autograd` 的自动微分引擎，他支持任意计算图（计算图就是构建好的神经网络）的自动梯度计算：

![image-20260306021829265](https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260306021829380.png)

如何理解自动微分呢？大白话来说，其实就是**自动求梯度**

举个例子（以线性回归为例，如上图所示）

*   假设模型参数是：$y = w \cdot x + b$
*   现在提供了特征值x，目标值y
*   初始化随机 权重w和偏置b
*   通过模型 $y' = w \cdot x + b$ 可以得到拟合结果
*   然后对拟合结果与真实结果求得损失函数
*   接下来利用损失函数，对w和b求偏导，得到梯度下降的梯度

$$
w_n = w_{n-1} - \eta \frac{\partial Loss}{\partial w}
$$

$$
b_n = b_{n-1} - \eta \frac{\partial Loss}{\partial b}
$$



*   然后更新w和b，重新拟合

而自动微分模块，其实就是根据损失函数Loss自动求得权重w和偏置b的梯度。

接下来我们使用这个结构进行自动微分模块的介绍。我们使用 `backward()` 方法实现梯度的计算，`grad` 属性来访问梯度

```python
import torch

# 1. 准备数据：参数与目标值
x = torch.tensor(5) #特征
y = torch.tensor(0.)

# 2. 初始化参数：权重与偏置
w = torch.tensor(1., requires_grad=True, dtype=torch.float32)
b = torch.tensor(3., requires_grad=True, dtype=torch.float32)

# 3. 构建神经网络并输出值
z = w * x + b

# 4. 计算损失
loss = torch.nn.MSELoss()
loss = loss(z, y)

# 5. 反向传播，自动微分，计算梯度
loss.backward()

# 6. 访问梯度
print(w.grad)
print(b.grad)
```

```python
import torch

# 1. 准备数据：参数与目标值
x = torch.ones(2,5)
y = torch.zeros(2,3)

# 2. 初始化参数：权重与偏置
w = torch.randn(5,3, requires_grad=True)
b = torch.randn(3,requires_grad=True,)

# 3. 构建神经网络并输出值
z = torch.matmul(x, w) + b

# 4. 计算损失
loss = torch.nn.MSELoss()
loss = loss(z, y)

# 5. 反向传播，自动微分，计算梯度
loss.backward()

# 6. 访问梯度
print(w.grad)
print(b.grad)
```

### 3. PyTorch 训练模型一般步骤

通过 **PyTorch** 训练一个模型一般可以分为以下 4 个步骤：

**1. 准备数据**

- 自定义 `Dataset` 类
    - 实现`__init__(self)`：加载原始数据，保存数据处理需要的配置
    - 实现 `__getitem__(index)`：根据索引返回对应位置的样本数据
    - 实现 `__len__()`：返回数据集的总样本数
- 使用 `DataLoader` 加载数据
    - 设置 `batch_size`：按批次读取数据
    - 设置 `shuffle=True`：打乱样本顺序，避免模型陷入局部最优

**2. 构建模型**

- 使用 `torch.nn.Module` 搭建神经网络结构
- 在 `forward()` 方法中定义前向计算过程

**3. 定义损失函数与优化器**

- 选择损失函数（如：均方误差 `MSELoss`）用于衡量预测值与真实值的差距
- 选择优化器（如：`SGD`、`Adam`）用于更新模型参数

**4. 模型训练**

- 使用两层循环进行训练
    - 外层：`epoch`（训练轮数）
    - 内层：`step`（每个 batch 的训练次数）
        - `step ≈ 样本总数 / batch_size`
- 每个 step 的训练流程：
    1. 前向计算（`model(x)`）
    2. 计算损失（`loss`）
    3. 清空梯度（`optimizer.zero_grad()`）
    4. 反向传播求梯度（`loss.backward()`）
    5. 更新参数（`optimizer.step()`）

### 4. Dataset 和 DataLoader

一般案例中，送入模型中的是DataLoader中的一批一批的数据，而DataLoader中的数据是从Dataset数据集中获取的。在很多任务中，Dataset数据集已经有别的组织或者框架给我们封装好了，但是也有可能没有给我们封装好，有的时候我们也需要自己从原始数据封装为Dataset供模型训练。

#### 4.1 Dataset

Dataset是Pytorch中的一个抽象类，用于表示数据集。它**允许用户自定义数据集的接口，使得用户可以使用统一的形式来访问数据**。

举个例子：

*   Dataset就像“整理好的快递箱”
*   每个快递箱（Dataset）里装着多个包裹（样本）
*   每个包裹上贴了编号（索引）
*   快递员（DataLoader）能按编号快速找到并取出包裹，不用翻遍整个箱子

**定义方法：**

PyTorch 要求自定义Dataset必须继承 `torch.utils.data.Dataset`，并实现 **3 个核心方法** —— 这 3 个方法就是“数据容器的说明书”，告诉框架“数据有多少、怎么取”。

*   `__init__(self)`：加载原始数据，保存数据处理需要的配置，如样本的大小，总个数等。相当于“把所有包裹装进快递箱”
*   `__len__(self)`：作用是告诉框架，容器中有多少个样本，返回总样本个数即可
*   `__getitem__(self, index)`：通过数据的索引，获取样本。

```python
# 自定义Dataset
import torch
from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self):
        # 1. 初始化数据，例如读取文件
        self.data = ['李云龙','楚云飞','赵刚','丁伟','孔捷','常乃超','魏大勇','秀芹']
        self.total = len(self.data)

    def __getitem__(self, index):
        # 2. 获取索引对应的数据
        return self.data[index]


    def __len__(self):
        # 3. 返回数据集的长度
        return self.total

if __name__ == '__main__':
    dataset = MyDataset()
    print(dataset[1])
```

#### 4.2 DataLoader

DataLoader是 PyTorch 中用于批量加载数据的工具。
它允许用户根据自定义的Dataset对象创建一个数据加载器，用于**批量加载和处理数据**。
DataLoader可以**按照批次大小对数据集进行分割**，并**提供多线程数据加载和预取功能**。

```python
# DataLoader的创建
import torch
from torch.utils.data import DataLoader

# 创建DataLoader
# batch_size: 每次批次的大小（一般是2的倍数）
# shuffle: 是否打乱数据
dataloader = DataLoader(MyDataset(), batch_size=2, shuffle=False)
	# 每次取两个样本（Tensor）装箱，打包成一个data（Tensor）
    # 此处示例使用的是列表而非Tensor，所以返回data的类型也是list而不是Tensor

# 获取批次数据
for data in dataloader:
    print(data)
```

### 1. 人工神经网络（Artificial Neural Network，简写为ANN）

简称神经网络（NN）

来源不同树突（树突都会有不同的权重）的信息，进行加权计算，输入到细胞中做加和，再通过激活函数输出细胞值。

> **`nn.Linear()`全连接神经网络**：第 N 层的每个神经元和第 N-1层 的所有神经元相连
>
> 每一个神经元都相当于做一次**逻辑回归**（线性回归＋激活函数）【也存在做其他处理的】

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307011116329.png" alt="image-20260307011116205" style="zoom:67%;" />

神经网络中信息只向一个方向移动，即从输入节点向前移动，通过隐藏节点，再向输出节点移动。每个连接都有一个权重值。

其中的基本部分是:

1. **输入层**: 即输入 x 的那一层（x 即**特征**）
2. **输出层**: 即输出 y 的那一层（y 即**标签**）
3. **隐藏层**: 输入层和输出层之间都是隐藏层

![image-20260307011257281](https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307011257368.png)

每一个神经元工作时，**前向传播**会产生两个值，**内部状态值**和**激活值**；**反向传播**时会产生**激活值梯度**和**内部状态值梯度**。

通过控制每个神经元的内部状态值、激活值的大小；每一层的内部状态值的方差、每一层的激活值的方差可让整个神经网络工作的更好。

### 2. 激活函数

#### 2.1 计算流程

在一个神经元中，激活函数的使用位于**加权求和之后**，**输出之前**。具体流程如下：

1.  **接收输入**：神经元接收来自上一层多个神经元的输出信号（记为 $x_1, x_2, ..., x_n$）。
2.  **加权求和（线性变换）**：将每个输入信号乘以对应的权重（$w_1, w_2, ..., w_n$），并加上一个偏置项（$b$）。
    *   计算中间值 $z$：
        $$z = \sum_{i=1}^{n} (w_i \cdot x_i) + b$$
3.  **应用激活函数（非线性变换）**：将计算得到的 $z$ 作为输入，传递给激活函数 $f(\cdot)$。
    *   计算输出 $a$：
        $$a = f(z)$$
4.  **输出结果**：激活函数的输出 $a$ 作为该神经元的最终输出，传递给下一层神经元或作为最终结果。

#### 2.2 核心作用

*   **引入非线性**：如果没有激活函数，无论神经网络有多少层，它都等价于一个单层的线性模型，无法学习复杂的模式（如图像识别、自然语言处理等）。激活函数赋予了网络拟合复杂非线性关系的能力。
*   **决定神经元是否“激活”**：某些激活函数（如 ReLU 或 Sigmoid）可以将输出限制在特定范围，或者将负值变为零，模拟生物神经元“兴奋”或“抑制”的状态。
*   **梯度传播**：在反向传播过程中，激活函数的导数用于计算梯度，从而更新网络的权重。

#### 2.3 常见激活函数

##### 2.3.1 sigmoid 激活函数

激活函数公式：

$$
f(x) = \frac{1}{1 + e^{-x}}
$$
激活函数求导公式：

$$
f'(x) = (\frac{1}{1+e^{-x}})' = \frac{1}{1+e^{-x}}(1 - \frac{1}{1+e^{-x}}) = f(x)(1 - f(x))
$$
sigmoid 激活函数的函数图像如下:

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307012559282.png" alt="image-20260307012559177" style="zoom:67%;" />

从 sigmoid 函数图像可以得到，sigmoid 函数可以**将任意的输入映射到 (0, 1) 之间**，当输入的值大致在 <-6 或者 >6 时，意味着输入任何值得到的激活值都是差不多的，这样会丢失部分的信息。比如：输入 100 和输出 10000 经过 sigmoid 的激活值几乎都是等于 1 的，但是输入的数据之间相差 100 倍的信息就丢失了。

对于 sigmoid 函数而言，输入值在 **[-6, 6]** 之间输出值才会有**明显差异**，输入值在 **[-3, 3]** 之间才会有**比较好的效果**。

通过上述导数图像，我们发现**导数数值范围是 (0, 0.25)**，当输入 <-6 或者 >6 时，sigmoid 激活函数图像的**导数接近为 0**，此时**网络参数将更新极其缓慢，或者无法更新**。

一般来说，sigmoid 网络在 **5 层之内**就会产生**梯度消失**现象。而且，该激活函数并不是以 0 为中心的，所以在实践中这种激活函数使用的很少。sigmoid函数一般只用于==二分类的输出层==。

##### 2.3.2 tanh 激活函数

Tanh 叫做双曲正切函数，其公式如下：

$$
f(x) = \frac{1 - e^{-2x}}{1 + e^{-2x}}
$$
激活函数求导公式:

$$
f'(x) = (\frac{1-e^{-2x}}{1+e^{-2x}})' = 1 - f^2(x)
$$
Tanh 的函数图像、导数图像如下：

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307012843287.png" alt="image-20260307012843183" style="zoom:67%;" />

由上面的函数图像可以看到，Tanh 函数**将输入映射到 (-1, 1) 之间**，**图像以 0 为中心**，在 0 点对称，当输入 大概<-3 或者 >3 时将被映射为 -1 或者 1。其**导数值范围 (0, 1)**，当输入的值大概 <-3 或者 > 3 时，其导数近似 0。

与 Sigmoid 相比，它是以 0 为中心的，使得其**收敛速度要比 Sigmoid 快**，减少迭代次数。然而，从图中可以看出，Tanh 两侧的导数也为 0，同样会造成**梯度消失**。

若使用时可**在==隐藏层==使用tanh函数，在输出层使用sigmoid函数**。

##### 2.3.3 ReLU（LeakRelu）激活函数

ReLU 激活函数公式如下：

$$
f(x) = \max(0, x)
$$
激活函数求导公式:

$$
f'(x) = 0\text{或}1
$$
函数图像如下:

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307013033081.png" alt="image-20260307013032976" style="zoom:67%;" />

从上述函数图像可知，ReLU 激活函数**将小于 0 的值映射为 0，而大于 0 的值则保持不变**，它**更加重视正信号，而忽略负信号**，这种激活函数运算更为简单，能够提高模型的训练效率。

但是，如果我们网络的参数采用随机初始化时，很多参数可能为负数，这就使得输入的负值会被舍去，而输入的正值则会保留，这可能在大部分的情况下并不是我们想要的结果。

ReLU 的导数图像如下:

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260307013125528.png" alt="image-20260307013125433" style="zoom:67%;" />

ReLU是目前最常用的激活函数。从图中可以看到，当x<0时，ReLU导数为0，而当x>0时，则不存在饱和问题。所以，**ReLU 能够在x>0时保持梯度不衰减，从而缓解梯度消失问题**。然而，随着训练的推进，部分输入会落入小于0区域，导致对应权重无法更新。这种现象被称为**“神经元死亡”**。

与sigmoid相比，RELU的优势是：

*   采用sigmoid函数，计算量大（指数运算），反向传播求误差梯度时，求导涉及除法，计算量相对大，而采用Relu激活函数，整个过程的计算量节省很多。
*   sigmoid函数反向传播时，很容易就会出现梯度消失的情况，从而无法完成深层网络的训练。
*   Relu会使一部分神经元的输出为0，这样就造成了网络的稀疏性，并且减少了参数的相互依存关系，**缓解了过拟合问题的发生**。

##### 2.3.4 SoftMax

softmax用于多分类过程中，它是二分类函数sigmoid在**多分类**上的推广，目的是**将多分类的结果以概率的形式展现出来**。

计算方法如下图所示：

$$
softmax(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$
**整体作用:** 将分子除以总和，实现**归一化（Normalization）**，确保所有输出值的和等于 1

Softmax 直白来说就是将网络输出的 logits 通过 softmax 函数，就**映射成为(0,1)的值**，而这些值的**累和为1**（满足概率的性质），那么我们将它理解成概率，**选取概率最大（也就是值对应最大的）节点，作为我们的预测目标类别**。

##### 2.3.5 ELU

ELU 函数的公式为：
$$
\text{elu}(x) = \begin{cases} x & x \geq 0 \\ \alpha(e^x - 1) & x < 0 \end{cases}
$$
其中 a 是一个正数，通常取 1。

ELU 函数在 x<0 时具有负指数特性，可以**避免 ReLU 函数的死亡神经元问题**，并且对于一些**复杂的任务，效果会略微好于 ReLU 函数**。（ELU 相对 LeakRelu 在负值计算时间更长）

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260309111640923.png" alt="image-20260309111640745" style="zoom:150%;" />

##### 2.3.6 SELU

SELU 是在 ELU 的基础上乘以缩放系数 $\lambda$（lambda）
$$
\text{selu}(x) = \lambda \begin{cases} x & x \ge 0 \\ \alpha (e^x - 1) & x < 0 \end{cases}
$$
SELU 函数则是在 ELU 函数的基础上提出的改进方法，旨在通过对网络的初始化和激活函数进行约束来一定程度 **解决深层神经网络中的梯度消失和梯度爆炸**等问题。具体地，SELU 函数**要求网络满足若干假设条件**（例如权重应该服从一定的高斯分布），并且在这些条件成立的情况下，保证网络的**输出服从一定的分布**。

SELU 函数则需要满足若干假设条件，因此并不是适用于所有类型的神经网络。对于那些**“标准”的神经网络结构**（例如 MLP 或 CNN），使用 SELU 函数可能会带来较好的性能提升，但对于其他类型的网络（例如 LSTM 或 GAN），使用 SELU 函数的效果则可能不如预期。

#### 2.4 激活函数选择

对于**隐藏层**:

1.  优先选择ReLU激活函数
2.  如果ReLu效果不好，那么尝试其他激活，如Leaky ReLu等。
3.  如果你使用了ReLU，需要注意一下Dead ReLU问题，避免出现大的梯度从而导致过多的神经元死亡。
4.  少用使用sigmoid激活函数，可以尝试使用tanh激活函数
5.  **如果权重初始化采用Xavier初始化，可以选用tanh激活函数或sigmoid激活函数**
6.  **如果权重初始化采用kaiming初始化，可以选用relu激活函数**

对于**输出层**:

1.  二分类问题选择sigmoid激活函数
2.  多分类问题选择softmax激活函数
3.  回归问题选择identity激活函数

### 3. 交叉熵损失和均方误差损失对比分析（使用SoftMax） 

**均方误差(回归)公式**
$$
MSE = \frac{1}{n}\sum_{i}^{n}(\hat{y}_i - y_i)^2
$$
**交叉熵损失公式**
$$
L = \frac{1}{N}\sum_{i}L_i = -\frac{1}{N}\sum_{i}\sum_{c=1}^{M}y_{ic}\log(p_{ic})
$$
**均方误差与交叉熵损失对比：**

- **相同点：**当输出值与真实值接近的话，cross_entropy 和 rmse 的值都会接近 0
- **cross_entropy 具有 rmse 不具有的优点：**避免学习速率降低的情况。(注意这种效果仅限于输出层，隐藏层的学习速率与其使用的激活函数密切相关。)
- 主要原因是**逻辑回归配合 MSE 损失函数时，采用梯度下降进行学习时，会出现模型一开始训练时，学习速率非常慢的情况（MSE 损失函数）**

- **均方损失：**假设误差是正态分布，适用于**线性的输出(如回归问题)**，特点是对于与真实结果差别越大，则惩罚力度越大，这并不适用于分类问题
- **交叉熵损失：**假设误差是二值分布，可以视为预测概率分布和真实概率分布的相似程度。在**分类问题**中有良好的应用。

### 4. **数据集为什么要划分为训练集、验证集、测试集**

**1. 训练集（Training Set）**
用于**训练模型参数**，让模型学习数据中的规律。

**2. 验证集（Validation Set）**
用于**调节超参数和选择模型**，并判断是否出现**过拟合**。

**3. 测试集（Test Set）**
用于**最终评估模型性能**，检验模型在**未知数据上的泛化能力**。
在最终评估前，测试集的信息是完全没有被模型获取过的。

**核心原因：**

- 避免模型只记住训练数据（过拟合）
- 保证模型评估结果**客观可靠**

**常见划分比例：**

- 训练集：60%~80%
- 验证集：10%~20%
- 测试集：10%~20%

**一句话总结：**

> **<span style='color:red'>为了防止人工调参造成的测试集的信息泄露</span>**

### 5. `nn.Linear()` 全连接神经网络

**第 N 层的每个神经元都与第 N−1 层的所有神经元相连**，因此称为**全连接层（Fully Connected Layer）**。

每个神经元的计算本质是一个**线性变换**：
$$
y = wx + b
$$
其中：

- $x$：输入特征
- $w$：权重矩阵
- $b$：偏置
- $y$：输出结果

如果在线性变换之后再接**激活函数**（如 ReLU、Sigmoid 等），就形成了一个完整的神经元计算过程，因此可以理解为：

> 每一个神经元都相当于做一次 **逻辑回归（线性变换 + 激活函数）**

在 PyTorch 中使用 `nn.Linear()` 来实现该层，因此也称为：

- **线性层（Linear Layer）**
- **全连接层（Fully Connected Layer）**

------

**输入数据要求**

`nn.Linear()` 只支持 **二维 Tensor** 输入，即 shape = (样本数batch_size, 特征数feature)

------

**高维数据的处理**

对于图像等高维数据（如 `(batch, channel, height, width)`），
在进入线性层之前需要先展开为一维向量，因此通常需要使用`nn.Flatten()`展开层

作用：

```
(batch, channel, height, width)
          ↓
(batch, channel × height × width)
```

即把多维特征**展开为一维特征向量**，才能输入到 `nn.Linear()`。

**简单示例**

```python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Flatten(),        # 展平
    nn.Linear(784, 128), # 全连接层
    nn.ReLU(),           # 激活函数
    nn.Linear(128, 10)
)
```

> 这里表示：784维输入 → 128个神经元 → 10维输出

### 1. $w$的初始分布

在神经网络训练开始前，需要对模型参数 **w（权重）进行初始化**。  
合理的初始化可以避免：

- 梯度消失
- 梯度爆炸
- 网络训练缓慢

常见的初始化方法有：

- **Kaiming 初始化（He 初始化）**
- **Xavier 初始化（Glorot 初始化）**

| 方法            | 公式                                              | 适用激活函数     |
| --------------- | ------------------------------------------------- | ---------------- |
| Xavier Uniform  | $\sqrt{\frac{6}{\text{fan\_in}+\text{fan\_out}}}$ | sigmoid / tanh   |
| Kaiming Uniform | $\sqrt{\frac{3}{\text{fan\_in}}}$                 | ReLU / LeakyReLU |

####  1.1 均匀分布（Uniform Distribution）

均匀分布也叫 **矩形分布**。

**特点：**在某个区间内，每个值出现的概率完全相同。

**数学定义**

如果随机变量随机变量X服从区间[a,b]上的均匀分布，即 $X \sim \mathcal{U}(a, b)$，则概率密度函数为：

$$
f(x) = \begin{cases} 
\frac{1}{b-a} & a \leq x \leq b \\
0 & \text{其他}
\end{cases}
$$

含义

- 区间 $[a, b]$ 内概率密度为常数
- 区间外概率为 0

##### 均匀分布与正态分布对比

在机器学习中常见两种随机初始化：

- **均匀分布（Uniform）**

| -------- | ---------------------- |

#### 1.2 Kaiming_Uniform_ 初始化

`kaiming_uniform_` 是 **PyTorch 默认常见的权重初始化方法**之一。

官网默认公式是  $\sqrt{\frac{3}{\text{fan\_in}}}$

示例代码：

```python
w = torch.empty(128, 256)
nn.init.kaiming_uniform_(w, a=math.sqrt(5), mode='fan_in', nonlinearity='leaky_relu')
```

含义：

- `fan_in` ：输入神经元数量
- `fan_out`：输出神经元数量
- `a`：LeakyReLU 的负斜率参数

---

**示例计算**

假设：$fan_{in} = 256$

计算过程：

- $gain = \sqrt{\frac{2}{1 + a²}}$

- 当 a = √5 时， $gain = \sqrt{\frac{2}{1 + 5}} = \sqrt{\frac{1}{3}}$

- 接着计算标准差：$\text{std} = \frac{\text{gain}}{\sqrt{fan_{in}}} = \frac{\sqrt{1/3}}{\sqrt{256}}$

- 最后得到均匀分布范围：$bound = \sqrt{3} × std$

- 因此：
    $$
    w \sim \mathcal{U}(-\text{bound}, \text{bound})
    $$

---

**Kaiming Uniform 分布总结**

| 名称     | 说明                                                         |
| -------- | ------------------------------------------------------------ |
| 分布类型 | 均匀分布（Uniform）                                          |
| 范围     | $\left[-\text{gain} \cdot \sqrt{\frac{3}{\text{fan}}}, \text{gain} \cdot \sqrt{\frac{3}{\text{fan}}}\right]$ |
| 默认参数 | `a=0, mode='fan_in', nonlinearity='leaky_relu'`              |
| 应用场景 | Linear、Conv 等网络层初始化，适合 ReLU / LeakyReLU           |

#### 1.3 Xavier_Uniform_ 初始化

Xavier 初始化是另一种常见权重初始化方式。

**分布公式**
$$
w \sim \mathcal{U}(-\text{limit}, \text{limit})
$$

其中：$\text{limit} = \sqrt{\frac{6}{\text{fan\_in} + \text{fan\_out}}}$

**参数说明**

- `fan_in`：输入神经元数量
- `fan_out`：输出神经元数量

---

**示例计算**

假设：

- 输入层：784
- 隐藏层：300

则：

$\text{fan\_in} + \text{fan\_out} = 784 + 300 = 1084$

$\text{limit} = \sqrt{\frac{6}{1084}}$

最终：

$$
w \sim \mathcal{U}\left(-\sqrt{\frac{6}{\text{fan\_in}+\text{fan\_out}}}, \sqrt{\frac{6}{\text{fan\_in}+\text{fan\_out}}}\right)
$$

***

**适用场景**

Xavier 初始化通常适用于：

- **tanh**
- **sigmoid**

### 2. 对象名()

在 Python 中，`对象名()` 这种写法表示**“调用”**该对象。

简单来说，它的含义是：“让这个对象执行它所定义的动作”。

**核心解释：**

在 Python 中，函数和类都是“对象”。

1.  **如果对象是一个函数**：`对象名()` 就是**执行该函数**内部的代码。
2.  **如果对象是一个类**：`对象名()` 就是**创建该类的一个实例**（也就是实例化对象）。
3.  **如果对象是一个普通的实例**：只有当这个类定义了 `__call__` 方法时，`实例名()` 才能执行，否则会报错。

**底层原理：**
当你在对象后面加上 `()` 时，Python 实际上是在调用该对象的 `__call__` 方法。

---

**简单示例**

**情况一：对象是函数（最常见）**

这是最直观的用法，表示执行函数。

```python
# 定义一个函数对象，名字叫 greet
def greet():
    print("你好，世界！")

# 此时 greet 是一个对象（函数对象）
print(type(greet))  # 输出：<class 'function'>

# 使用 greet() 调用它
greet()  # 输出：你好，世界！
```

**情况二：对象是类**

这种写法用于创建一个新的对象实例。

```python
# 定义一个类，名字叫 Dog
class Dog:
    def __init__(self):
        print("一只小狗被创建出来了！")

# 使用 Dog() 调用类
my_dog = Dog()  # 输出：一只小狗被创建出来了！
```

**情况三：对象是实例（进阶用法）**

普通的实例后面加 `()` 会报错，除非这个类实现了 `__call__` 方法。这让对象可以像函数一样被调用。

```python
class Multiplier:
    def __init__(self, factor):
        self.factor = factor
    
    # 定义 __call__ 方法，让实例可以像函数一样被调用
    def __call__(self, number):
        return number * self.factor

# 创建一个对象，乘数设为 5
times_five = Multiplier(5)

# times_five 是一个实例对象，但我们可以在它后面加 ()
# 这就是“对象名()”的第三种情况
result = times_five(10) 

print(result)  # 输出：50
```

### 3. 图像任务归一化、标准化 torchvision.transforms

在 **torchvision.transforms** 中，归一化与标准化主要通过几个常用的 **transform** 完成，通常用于数据预处理，并在 `Dataset` 或 `DataLoader` 读取数据时执行。

#### 3.1 归一化`transforms.ToTensor()`

将图像转换为 **PyTorch Tensor**，并自动完成一次简单归一化。

基本语法：==`transforms.ToTensor()`==

作用：

- 将 **PIL Image 或 numpy.ndarray** 转换为 **Tensor**
- **转换数据类型**：数据类型变为 `float32`，因为 PyTorch 的神经网络层通常处理浮点数数据
- **缩放像素值**：像素值从 **[0,255] → [0,1]**，这是通过将每个像素值除以 255 来实现的。
- **增加通道维度**：对于单通道的灰度图像，它会增加一个通道维度，使其成为具有两个维度的张量，即 **[channels, height, width]**。对于三通道的彩色图像，它将保持三个通道。

---

#### 3.2 标准化`transforms.Normalize()`

用于对 **图像张量的每个通道进行标准化**。将数据的分布调整为均值为 0，标准差为 1 的分布，从而减少了不同特征之间的尺度差异，有助于模型更快地收敛，并且对学习率的选择更为鲁棒。

基本语法：==`transforms.Normalize(mean, std, inplace=False)`==

- `mean`

    - 类型：`sequence`

    - 含义：每个 **通道的均值**

    - 例如 RGB 图像：

        ```python
        mean = [0.5, 0.5, 0.5]
        ```

        表示：R通道均值 = 0.5，G通道均值 = 0.5，B通道均值 = 0.5

-  `std`

    - 类型：`sequence`
    - 含义：每个 **通道的标准差**

- `inplace`

    - 类型：`bool`
    - 默认：`False`
    - 含义：
        - `False`：返回新的 Tensor
        - `True`：直接在原 Tensor 上修改

**计算方式**

`Normalize` 实际执行：

```
output = (input - mean) / std
```

并且是 **按通道计算**：

```
R = (R - mean_R) / std_R
G = (G - mean_G) / std_G
B = (B - mean_B) / std_B
```

---

#### 3.3 `transforms.Compose()`

用于 **组合多个 transform**。

基本语法：==`transforms.Compose(transforms_list)`==

参数:`transforms_list`

- 类型：`list`
- 含义：需要按顺序执行的 transform

------

#### 3.4 完整示例

```python
from torchvision import transforms

transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize(
        mean=[0.5,0.5,0.5],
        std=[0.5,0.5,0.5]
    )
])

img_tensor = transform(img)
```

执行流程：

```
PIL Image
   ↓
ToTensor()      # 转Tensor并缩放到[0,1]
   ↓
Normalize()     # 标准化
   ↓
Tensor(C,H,W)
```

#### 4. 早停（Early Stopping）

**早停**是一种正则化技术，用于**避免过拟合**。原理是：

- 在训练过程中持续监控验证集指标（如验证损失或验证准确率）
- 当验证指标不再改善时，提前停止训练
- 保存验证指标最佳时的模型，避免继续训练导致过拟合

---

**主要参数说明**

1. **min_delta**（最小变化阈值）

- **含义**：将一次变化视为“改进”的最小阈值
- **作用**：如果验证指标的绝对变化小于 `min_delta`，则不视为改进
- **示例**：`min_delta=0.001` 时，验证损失从 0.5 变为 0.5005（变化 0.0005 < 0.001）不算改进

2. **Patience**（耐心值）

- **含义**：允许验证指标不改善的轮数（epochs）
- **作用**：连续 `Patience` 个 epoch 无改进后停止训练
- **示例**：`patience=5` 时，连续 5 个 epoch 无改进则停止

---

**工作原理示例**

假设 `patience=3`，`min_delta=0.001`：

- Epoch 1-5：验证损失持续下降 → 继续训练
- Epoch 6-8：验证损失变化 < 0.001 或上升 → 开始计数
- Epoch 9：连续 3 个 epoch 无改进 → 触发早停，保存 Epoch 5 的模型

这样可以防止模型在训练集上过度拟合，同时节省训练时间。

### 7. nn.Sequential() 按顺序构建神经网络层

`nn.Sequential()` 是 PyTorch 中用于**按顺序构建神经网络层的容器**。它可以把多个网络层按照给定顺序组合成一个整体模型，并在前向传播时**自动按顺序依次执行每一层**。

#### 7.1 基本作用

`nn.Sequential()` 的作用是：

- **顺序组合多个网络层**
- **自动完成前向传播流程**
- **减少手写 `forward()` 的代码**

当输入数据进入模型时，数据会：

​	输入 → 第1层 → 第2层 → 第3层 → ... → 输出

**每一层的输出会自动作为下一层的输入**

#### 7.2 基本语法

```python
nn.Sequential(
    层1,
    层2,
    层3,
    ...
)
```

例如：

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(10, 20),
    nn.ReLU(),
    nn.Linear(20, 1)
)
```

网络结构为：

```python
输入(10)
   ↓
Linear(10 → 20)
   ↓
ReLU
   ↓
Linear(20 → 1)
   ↓
输出
```

#### 7.3 前向传播过程

如果输入：

```python
x = torch.randn(5, 10)
y = model(x)
```

执行顺序为：

```python
x
↓
Linear(10,20)
↓
ReLU()
↓
Linear(20,1)
↓
y
```

即：
$$
y = Linear_2(ReLU(Linear_1(x)))
$$
整个过程 **自动完成，不需要自己写 `forward()`**。

#### 7.4 三种创建方式

**写法1：直接传入层（最常用）**

```python
model = nn.Sequential(
    nn.Linear(10,20),
    nn.ReLU(),
    nn.Linear(20,1)
)
```

------

**写法2：使用 `OrderedDict`指定层名称**

```python
from collections import OrderedDict

model = nn.Sequential(OrderedDict([
    ("fc1", nn.Linear(10,20)),
    ("relu", nn.ReLU()),
    ("fc2", nn.Linear(20,1))
]))
```

------

**写法3：先创建再添加（动态构建）**

```python
model = nn.Sequential()

model.add_module("fc1", nn.Linear(10,20))
model.add_module("relu", nn.ReLU())
model.add_module("fc2", nn.Linear(20,1))
```

特点：

- 可以动态生成网络
- 适合循环添加

#### 7.5 与普通模型的区别

不用 `Sequential` 时，需要自己写 `forward()`：

```python
class Net(nn.Module):

    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(10, 20)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(20, 1)

    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x
```

使用 `Sequential`：

```python
model = nn.Sequential(
    nn.Linear(10,20),
    nn.ReLU(),
    nn.Linear(20,1)
)
```

**Net类方式：**

- 可以在 forward 中添加条件判断、循环、分支等复杂逻辑

- 可以访问中间层的输出用于其他用途

**Sequential方式：**

- 只能按顺序执行，适合简单的线性堆叠

- 无法在中间添加复杂逻辑

---

**两种方式结合示例**

```python
from torch import nn

class NeuralNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()  # 展平输入，[batch, 1, 28, 28] -> [batch, 28*28]
        
        # 先初始化 Sequential
        self.network = nn.Sequential()
        
        # 第1层：784 -> 100
        self.network.add_module('fc1', nn.Linear(28*28, 100))
        self.network.add_module('relu1', nn.ReLU())
        
        # 使用循环动态添加网络层
        # 中间18层，每层都是100 -> 100
        for i in range(18):
            self.network.add_module(f'fc{i+2}', nn.Linear(100, 100))
            self.network.add_module(f'relu{i+2}', nn.ReLU())
        
        # 输出层：100 -> 10（不需要激活函数）
        self.network.add_module('fc20', nn.Linear(100, 10))

    # 前向传播方法，调用 model(x) 会自动调用 forward(x)
    def forward(self, x):
        x = self.flatten(x)  # 展平输入
        x = self.network(x)  # 自动按顺序依次执行每一层
        return x
```

### 8. 反向传播

**反向传播（Backpropagation，BP）是神经网络训练时用来计算各层参数梯度并更新权重**的一种算法。

它的核心作用是：**根据模型预测误差，反向计算每一层参数对误差的影响，从而指导参数更新。**

可以把神经网络训练理解为两个阶段：**前向传播 + 反向传播**。

#### 8.1 前向传播（Forward Propagation）

在前向传播中，数据从输入层开始，依次经过各层神经元计算，最终得到模型的预测结果。

例如一个简单神经网络：

```
输入层 → 隐藏层 → 输出层
```

每一层神经元都会进行如下计算：
$$
z = wx + b
$$
再经过激活函数：
$$
a = f(z)
$$
最终得到预测值：
$$
\hat{y}
$$
然后利用真实值 $y$ 与预测值 $\hat{y}$ 计算**损失函数（Loss）**：
$$
Loss = L(y,\hat{y})
$$
损失函数表示模型预测的误差大小。

#### 8.2 反向传播（Backpropagation）

反向传播的任务是：
 **根据损失函数，计算每一个参数的梯度。**

也就是计算：
$$
\frac{\partial Loss}{\partial w}
$$
表示：
 **权重改变一点点，Loss 会变化多少。**

如果梯度为：

- 正数 → 权重应该减小
- 负数 → 权重应该增大

因此可以用梯度下降更新参数：
$$
w = w - \eta \frac{\partial Loss}{\partial w}
$$
其中：

- $w$：权重
- $\eta$：学习率
- $\frac{\partial Loss}{\partial w}$：梯度

------

**为什么叫“反向”传播**

因为梯度的计算顺序是：

```
输出层 → 隐藏层 → 输入层
```

也就是 **从网络最后一层向前计算**。

原因是梯度计算依赖**链式法则**：
$$
\frac{\partial Loss}{\partial w_1}
=
\frac{\partial Loss}{\partial z_2}
\cdot
\frac{\partial z_2}{\partial z_1}
\cdot
\frac{\partial z_1}{\partial w_1}
$$
也就是说：

**前一层的梯度依赖后一层的梯度。**

因此必须从 **输出层开始逐层往回算**。

------

**简单直观理解**

可以把反向传播理解成：

1️⃣ 神经网络先做一次预测（前向传播）
2️⃣ 计算预测误差（Loss）
3️⃣ 从最后一层开始计算误差对参数的影响
4️⃣ 把误差信息逐层向前传递
5️⃣ 得到所有参数的梯度
6️⃣ 用梯度下降更新参数

#### 8.3 在 PyTorch 中的实现

PyTorch 已经自动实现了反向传播（自动求导）。

典型训练代码：

```python
import torch
import torch.nn as nn

model = nn.Linear(10, 1)
criterion = nn.MSELoss()

x = torch.randn(5, 10)
y = torch.randn(5, 1)

# 前向传播
y_pred = model(x)

# 计算损失
loss = criterion(y_pred, y)

# 反向传播
loss.backward()
```

其中：

```python
loss.backward()
```

这一步就是 **自动进行反向传播计算梯度**。

梯度会保存在：

```python
param.grad
```

然后优化器更新参数：

```python
optimizer.step()
```

#### 8.4 为什么前向传播和反向传播要交替进行

- 反向传播必须依赖前向传播得到的损失值。
- 参数更新后模型已经改变，需要重新进行前向传播。
- 训练过程本质上是不断重复“预测—修正”的循环。

因此神经网络训练实际上是一个持续迭代的过程：

```
预测 → 计算误差 → 反向修正 → 再预测
```

通过不断交替执行前向传播和反向传播，模型的参数会逐渐优化，最终使预测误差不断减小。

#### 8.5 为什么要清空梯度

清空梯度的原因是 **PyTorch 的梯度默认会累积**。

当执行：

```python
loss.backward()
```

时，PyTorch 会计算梯度，并把结果**加到 `param.grad` 中**。

注意这里是：

```python
grad = grad + 新梯度
```

而不是：

```python
grad = 新梯度
```

这就叫 **梯度累积（gradient accumulation）**。

如果不清空梯度：

- 新梯度会和旧梯度相加
- 导致参数更新错误
- 影响模型训练效果

因此每一轮训练通常需要：

```python
optimizer.zero_grad()
```

来清除旧梯度，然后再执行：

```python
loss.backward()
```

计算新的梯度。

### 9. 梯度消失和梯度爆炸

**层数比较多的神经网络模型**在训练时也是会出现一些问题的，其中就包括梯度消失问题（gradient vanishing problem）和梯度爆炸问题（gradient exploding problem）。梯度消失问题和梯度爆炸问题一般**随着网络层数的增加会变得越来越明显**。

当反向传播求梯度时，求出梯度均小于1，根据反向传播的特性，梯度会逐层累积（连乘），导致从后往前梯度越来越小以至于接近0，此时发生**梯度消失**，接近于输出层的 hidden layer 3 等的权值更新相对正常，但前面的 hidden layer 1 的权值更新会变得很慢，导致前面的层权值几乎不变，仍接近于初始化的权值。

**梯度爆炸**则是大于1的梯度连乘导致梯度变得极大

### 10. 批归一化（Batch Normalization, BN）

指在每一层网络的线性变换（卷积/全连接）之后、非线性激活函数之前，对一个 mini‑batch 内的神经元激活值做“**标准化 + 线性变换**”的操作，使其在这一批数据上大致服从均值为 0、方差为 1 的分布，再通过可学习参数把分布“拉伸、平移”回适合当前任务的形状。

------

#### 10.1 具体算法

对某一层的一个神经元，在一个 mini‑batch 中的输入为

$\mathcal{B}=\{x_1,\dots,x_m\}$，步骤为：

- 计算批均值  $$\mu_{\mathcal{B}} = \frac{1}{m}\sum_{i=1}^m x_i$$
- 计算批方差  $$\sigma_{\mathcal{B}}^2 = \frac{1}{m}\sum_{i=1}^m (x_i-\mu_{\mathcal{B}})^2$$
- 归一化（减均值除方差）  $$\hat{x}_i = \frac{x_i-\mu{\mathcal{B}}}{\sqrt{\sigma_{\mathcal{B}}^2+\varepsilon}}$$
    - 这样得到的 $\hat{x}_i$ 在该批上均值约为 0、方差约为 1。
- 缩放和平移（可学习参数）  $$y_i = \gamma \hat{x}_i + \beta \equiv BN_{\gamma , \beta}(x_i)$$
    - 其中 $\gamma$ 为缩放因子，$\beta$ 为偏移因子，它们是和网络其它权重一起学习的。

这一步保证了：即便前面做了标准化，网络仍然可以通过学习到合适的 $\gamma,\beta$，恢复成任意需要的分布（例如类似 ReLU 适合的分布）。

------

#### 10.2 为什么要做批归一化？

- 减少“内部协变量偏移”（Internal Covariate Shift）

- 随着前面层参数不断更新，后面层看到的输入分布总是在变化，训练变得不稳定。

- BN 把每一层输入重新拉回到“均值 0、方差 1 的稳定分布”附近，使得后面层“看到”的数据分布变化变小，网络更容易训练。

- 缓解梯度消失/爆炸问题

- 输入范围被控制在一个比较合理的区间，激活函数不容易一直处在饱和区（例如 sigmoid 的两端），从而梯度更稳定。

- 可以使用更大学习率、收敛更快

- 分布被标准化后，参数更新不容易“抖得太离谱”，允许使用更大的学习率，加速训练。

- 具有一定正则化效果

- 每个 mini‑batch 的均值、方差是对真实分布的带噪估计，这种噪声在一定程度上类似于正则化，有助于减轻过拟合。

![image-20260309121410204](https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260309121410425.png)

---

#### 10.3 BN 在网络中的位置与使用要点

- 位置：一般放在 线性层（卷积/全连接） → BN → 激活函数 的顺序中。

- 训练阶段：用 mini‑batch 的均值、方差做上述 4 步。

- 推理阶段：用在训练过程中累计的“滑动平均均值和方差”，保持输出稳定。

- 参数：$\gamma,\beta$ 是需要学习的

---

#### 10.4 批归一化的作用与注意事项

**在每一层后都添加 BN 不一定会有最好效果**

##### 10.4.1 激活函数方面

- 在所有情况下，BN 都能显著提高训练速度。

- 没有 BN 时，使用 Sigmoid 容易出现严重的梯度消失问题。

- 使用 BN 后，sigmoid、tanh、ReLU 的准确度通常都有明显提升（虚线为无 BN，实线为有 BN）。

原因：BN 通过“减均值除方差”将激活值从饱和区（导数接近 0）拉到非饱和区（导数较大），从而缓解梯度消失。

##### 10.4.2 优化器方面

- 关系：ReLU + Adam ≈ ReLU + SGD + BN

- 含义：使用 BN 时，SGD 配合 BN 的效果可接近 Adam；使用 BN 后，优化器选择的影响会变小。

##### 10.4.3 批量大小（Batch Size）

- 小批量（如 batch size = 4）时，BN 可能降低性能。

- 原因：BN 依赖 mini-batch 的统计量，批量过小会导致估计不稳定。

- 建议：使用 BN 时避免过小的批量。

##### 10.4.4 数据不平衡（对标签进行 group by 即可得知）

- 在极度不平衡的数据（如二分类 99:1）上，BN 可能降低性能。

- 原因：BN 的统计量会被多数类主导，少数类分布被扭曲。

- 建议：极度不平衡时谨慎使用 BN，或考虑其他归一化方法。

##### 10.4.5 解决梯度消失问题

- BN 通过“减均值除方差”将每层输出的均值和方差规范化，把激活值从饱和区拉到非饱和区，从而缓解梯度消失。

- 机制：标准化后，激活值更可能落在激活函数的有效梯度区间，梯度更稳定。

##### 10.4.6 为什么批归一化后参数增加了但是训练速度却会提高？

每个 BN 层会引入两个可学习参数：

- γ（gamma）：缩放参数

- β（beta）：偏移参数

参数的增加会导致每个 epoch 训练所需时间增加，但使用 BN 后**收敛更快（epoch 数减少），允许更大学习率，梯度更稳定**，用少量额外参数和计算，换取更高效的优化过程，所以**总体时间更短**

### 12. Dropout

**Dropout** 是神经网络中一种常用的**正则化方法**，主要作用是**防止过拟合（Overfitting）**。

在训练神经网络时，Dropout 会在**每一次前向传播**中，**随机让一部分神经元失活（输出变为 0）**，也就是临时把这些神经元“丢弃”。

简单理解：每次训练时**随机关闭一部分神经元**，只让**剩余神经元参与计算和反向传播**

这样可以避免神经元之间**过度依赖**某些特征，从而提高模型的**泛化能力**。

每次训练使用的网络结构都**略有不同**。

![image-20260309142539167](https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260309142539386.png)

作用：

- 防止神经网络**过拟合**
- 减少神经元之间的**共适应（co-adaptation）**
- 相当于**训练了多个子网络并进行集成**

---

**为什么能防止过拟合？**

- **打破共适应**：单个神经元不能总是依赖固定的其他神经元，只能学到更鲁棒、**更具泛化性**的特征。

- **类似集成学习**：训练阶段相当于训练了许多共享参数的不同子网络，测试时所有神经元都打开，相当于对大量子网络进行“平均”，降低方差，减轻过拟合。

- 特别适合参数很多、容易记住训练集的深层网络。

---

**训练与测试的区别**

1️⃣ **训练阶段**

随机丢弃神经元：

```
y = Dropout(x)
```

2️⃣ **测试阶段**

不再丢弃神经元，而是**使用完整网络**，并进行**缩放补偿**（PyTorch等框架会自动处理）。

---

**PyTorch 使用方式**

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(p=0.5),   # 丢弃 50% 神经元
    nn.Linear(256, 10)
)
```

参数说明：

- p：丢弃概率

---

#### AlphaDropout（更常用）

AlphaDropout 是 Dropout 的一个变种，它在应用 Dropout 时使用了一个额外的缩放因子 alpha。

与标准 Dropout 相比，AlphaDropout **在将一些输出设置为零的同时，还会对剩余的输出进行缩放，以保持网络权重的期望值不变。**（均值与方差）

这种缩放可以保持网络的动态范围，有助于训练过程的稳定性。

AlphaDropout 通常用于带有 LeakyReLU 或 Parametric ReLU 激活函数的网络，因为这些激活函数在负输入时不饱和，Dropout 可能会导致这些神经元的权重更新不足。

### 1. 加载数据集时datahome参数的作用

`data_home` 是 `sklearn.datasets` 里很多数据集加载函数（如 `fetch_california_housing`）的一个参数，**用来指定“数据集在本地硬盘上的存放目录”**。

具体作用：

- **指定缓存路径**：  
  - 第一次下载数据集时，会把文件保存在 `data_home` 指定的文件夹下。  
  - 以后再调用同一个函数时，会**直接从这个目录读取缓存文件，而不用重新下载**。

- **不指定时的默认行为**：  
  - 如果 `data_home=None`（默认），sklearn 会使用用户主目录下的默认路径，例如类似：  
    - Windows：`C:\Users\你的用户名\scikit_learn_data`  
    - Linux/Mac：`~/scikit_learn_data`

- **什么时候需要自己设定？**  
  - 你想把所有数据集统一放在某个特定盘符/目录（比如 `D:\datasets\sklearn`）。  
  - 多个项目/多人共用同一份已下载好的数据集，避免重复下载。  
  - 你的默认用户目录空间不够，想把数据放到其他磁盘。

示例：

```python
from sklearn.datasets import fetch_california_housing

california = fetch_california_housing(data_home=r"D:\datasets\sklearn")
```

这样加州房价数据就会缓存在 `D:\datasets\sklearn` 下面。

一次训练过程中 **参与计算的样本数量**。

    - 训练更平滑

    - 再增加意义不大

- 决定 **能否收敛到最优或局部最优**

一般规律：

- **学习率过小**
    - 收敛速度慢
    - 训练时间长
- **学习率合适**
    - 在合理时间内收敛到较小损失
- **学习率过大**

### 3. 循环神经网络（Recurrent Neural Network， RNN）

**解决时序数据的处理能力，让神经网络拥有“记忆能力”**

循环神经网络（Recurrent Neural Network， RNN）是一种能够处理时序数据、保留历史信息的神经网络，核心是通过"循环结构"让网络在处理当前数据的时候，能用到"上一刻"的计算结果（类似于人可以记住之前发生的事情）。

核心特点：

- 时序性：输入数据有先后顺序（如时间步t1、t2、t3...）

- 记忆性：通过隐藏状态（Hidden state）存储历史信息

- 循环性：网络结构中，存在"反馈回路"（上一刻的输出影响当前时刻的输入）

#### 3.1 工作原理

1️⃣ RNN层具有环路，通过环路数据可以在层内循环。

把时序数据$x_0, x_1, x_2, ... x_n$输入层中，相应的会输出$h_0, h_1, h_2, ... h_n$

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260309230227422.png" alt="image-20260309230227196" style="zoom:80%;" />

2️⃣RNN如果以时间步为单位，那么展开形式为：

<img src="https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260309230250168.png" alt="image-20260309230249940" style="zoom:80%;" />

3️⃣RNN每一次计算的时候

- 有两个输入
  - 当前时间步的输入数据 $x_t$
  - 上一个时间步的输出数据 $h_t$ （不仅能获取上一个时间步的信息，还能获取前面所有时间步的信息）
- 有两个输出：（注意：这两个数据是一样的）
  - 当前时间步的输出数据 $O_t$
  - 当前时间步的隐藏（隐含）状态 $h_t$

4️⃣在RNN内部神经元，每一次计算的时候，公式如下：
$$
h_t = tanh(x_t \cdot w_{t1} + b_1 + h_{t-1} \cdot w_{t2} + b_2)
$$
其中：
- $x_t$：当前时间步的输入
- $w_{t1}$：输入权重的矩阵
- $b_1$：输入的偏置
- $h_{t-1}$：上一个时间步的隐藏状态（也就是输出）
- $w_{t2}$：隐藏状态的权重矩阵
- $b_2$：隐藏状态的偏置
- 激活函数使用 tanh

### 4. word2vec 与 embedding 的区别

Word2Vec 是一种常见的**词嵌入算法**，而 embedding 则是一种常用的**向量化表示方法**，在**自然语言处理**中经常被使用。

Word2Vec 是一种**基于神经网络的词向量训练算法**。它通过**学习上下文单词之间的关系，将每个单词映射到一个低维空间的向量表示中**。这些向量可以捕捉**单词**之间的语义相似性和句法关系，从而在自然语言处理领域提供了广泛的应用，如文本分类、情感分析、机器翻译等。

> Word2Vec 是两阶段模型，即：需要先训练 Word2Vec 得到所有单词的密集向量，再把密集向量带入到当前所做项目的模型中训练
>
> 两阶段模型的调参难度较大，所以当前已很少使用

而 embedding 则是一种**通用的数据压缩和向量化表示方法**，在不同领域都有广泛的应用。它可以**将高维度的数据（如图像、音频、文本等）转换为低维度的向量表示**，以便更好地进行处理和分析。在自然语言处理中，embedding 通常用来**表示词汇或者句子**，能够有效地表达语义信息和语境关系。

总的来说，Word2Vec 是一种特定的词向量训练算法，而 embedding 则是一种通用的向量化表示方法，其中在自然语言处理领域中，Word2Vec 常用于生成单词级别的嵌入，而 embedding 则可用于生成单词、短语、句子等多种粒度级别的嵌入。

### 5. 二进制交叉熵（Binary Cross Entropy, BCE）损失函数（负对数似然损失）

先对 logits 做 sigmoid：

$$
\text{cost}(h_\theta(x), y) = -\sum_{i=1}^{m} [y_i \log(h_\theta(x)) + (1-y_i)\log(1-h_\theta(x))]
$$

#### 5.1 单个神经元通过BCE进行二分类

这是处理二分类最经典、高效的方法

损失函数使用二进制交叉熵（Binary Cross Entropy, BCE）：
$$
loss = -[y \cdot log(p) + (1-y) \cdot log(1-p)]
$$
其中 $y$ 为真实标签（0或1），$p$为 sigmoid 输出。

- **结构**：输出层仅有 **1个** 神经元。

- **激活函数**：使用 **Sigmoid**，将输出压缩至 $[0, 1]$ 区间，直接代表“正类”的概率 $p$。

- **决策逻辑**：通常以 $0.5$ 为界限。$p > 0.5$ 判为正类（1），否则为负类（0）。

- **优势**：参数量少，计算简洁，逻辑直观。


示意图：

|输入|→ 隐藏层...→ |输出层(sigmoid, 1个神经元)|→ BCE损失函数|

#### 5.2 两个神经元通过Softmax进行二分类：

这种方法实际上是将二分类看作多分类（类别数为 2）的特例

损失函数使用交叉熵（Cross Entropy）：
$$
loss = -\sum_{i=1}^{2} y_i \cdot log(p_i)
$$
其中 $y_i$ 为 one-hot 标签（[1,0]或[0,1]），$p_i$ 为 softmax 输出概率。

- **结构**：输出层有 **2个** 神经元，分别代表类别 0 和类别 1 的得分。
- **激活函数**：使用 **Softmax**。它确保两个神经元的输出概率之和等于 1。
- **损失函数**：使用通用的**交叉熵损失**（Cross Entropy），标签通常采用 One-hot 编码（如 `[1, 0]`）。
- **决策逻辑**：哪个神经元的概率大，就选哪个类。
- **缺点**：对于二分类来说，这种方式稍微有些冗余，因为它多使用了一套权重和偏置。

示意图：

|输入|→ 隐藏层...→ |输出层(softmax, 2个神经元)|→ 交叉熵损失函数|

---

**区别总结：**

| **维度**     | **单神经元方案**       | **双神经元方案**              |
| ------------ | ---------------------- | ----------------------------- |
| **输出层**   | 1 个神经元             | 2 个神经元                    |
| **激活函数** | Sigmoid                | Softmax                       |
| **标签格式** | 整数 (0 或 1)          | One-hot 向量 ([1,0] 或 [0,1]) |
| **应用场景** | **专属二分类（推荐）** | 多分类（也可用于二分类）      |
| **效率**     | 更高（参数更少）       | 较低（参数冗余）              |

虽然两者在数学本质上是等价的（Sigmoid 是 Softmax 在二元情况下的特例），但在实际工程中，**单神经元 + Sigmoid + BCE** 更加简洁高效，是处理二分类问题的标准做法。

### 6. 回调函数（Callback Function）

简单来说，**回调函数（Callback Function）**就是“由你定义，但不由你直接调用”的函数。你把它作为参数传递给另一个函数，并在特定的时机（比如某个任务完成或事件发生时）由那个函数来执行。

------

**核心逻辑：控制权的反转**

在普通编程中，你调用系统的函数（A 调用 B）；而在回调模式中，你把自己的函数传给系统，让系统在合适的时候调用你（B 调用 A）。

**生活中的类比：**

- **普通调用：** 你去商店买东西，如果没有货，你只能在大厅一直等，直到货到。
- **回调调用：** 你去商店买东西发现没货，你留下了**电话号码**（回调函数），并告诉店员“货到了给我打电话”。然后你就可以回家做别的事了，等货一到，店员会主动拨通你的电话。

------

**代码示例**

回调函数最常见的用法是作为参数传递。

```Python
# 这是一个回调函数：定义了“货到后要做什么”
def on_item_arrived(item_name):
    print(f"收到通知：{item_name} 已经到货了，快去取吧！")

# 这是一个执行函数：模拟商店进货的过程
def shop_process(item, callback):
    print(f"商店正在为 {item} 补货...")
    # 模拟任务完成后触发回调
    callback(item)

# 调用时，将函数名作为参数传入
shop_process("显卡", on_item_arrived)
```

------

回调函数主要解决了以下两个问题：

- **异步处理：** 这是回调最广泛的应用。当一个操作（如读取大文件、发起网络请求）非常耗时，程序不需要停下来死等。它只需要设置一个“完成后请执行”的回调，就可以继续运行后续代码。
- **解耦（灵活扩展）：** 执行函数只需要知道在什么时候调用，而不需要关心调用的具体逻辑。具体的逻辑可以由调用者根据需求动态更换。

------

**回调函数的分类**

1. **同步回调：** 在主函数返回之前就执行了。例如 `list.sort(key=...)`，排序时会立即调用你提供的 key 函数。
2. **异步回调：** 在主函数返回之后，由某个事件、定时器或后台任务触发。这在 Web 开发（JavaScript）和图形界面编程（GUI）中非常常见。

------

**回调地狱（Callback Hell）：**

在复杂的异步逻辑中，如果一个回调函数里又嵌套了另一个回调，层层堆叠，代码会变得极其难以阅读和维护。

### 7. zip() 函数

**zip()** 函数用于将可迭代的对象作为参数，将对象中对应的元素打包成一个个元组，然后**返回由这些元组组成的列表**。

如果各个迭代器的元素个数不一致，则返回列表长度与最短的对象相同，利用 * 号操作符，可以将元组解压为列表。

zip 语法：==`zip([iterable, ...])`==

参数说明：

- iterable -- 一个或多个迭代器;

---

####  texts**,** labels **=** zip(*****batch)解析

`zip(*batch)` 是一个非常精妙的 Python 技巧，常用于 **矩阵转置** 或 **数据解包**。

> 在 `DataLoader` 的语境下，它的作用是将“格式 A”转换为“格式 B”：
>
> - **转换前 (`batch`)**：是一个列表，每个元素是一个元组 `(text, label)`。
>     - 结构：`[(text1, label1), (text2, label2), (text3, label3), ...]`
> - **转换后 (`texts, labels`)**：变成了两个独立的元组，一个全是文本，一个全是标签。
>     - 结构：`texts = (text1, text2, ...)`, `labels = (label1, label2, ...)`

**1. 拆解 `zip(*batch)` 的执行过程**

这里的关键在于星号 `*`（解包操作符）和 `zip` 函数的配合：

**第一步：`*batch` (Unpacking)**

假设 `batch_size=3`，`batch` 的内容如下：

```Python
batch = [("Hello world", 1), ("Good morning", 0), ("Amazing movie", 1)]
```

加上 `*` 后，相当于把列表拆开，变成了三个独立的参数传给 `zip`：

```Python
zip(("Hello world", 1), ("Good morning", 0), ("Amazing movie", 1))
```

**第二步：`zip(...)` (Zipping)**

`zip` 函数会从每个传入的元组中取出一个相同索引的元素，捆绑在一起：

- 取出所有索引为 `0` 的元素：`("Hello world", "Good morning", "Amazing movie")` -> 赋给 `texts`
- 取出所有索引为 `1` 的元素：`(1, 0, 1)` -> 赋给 `labels`

------

**2. 为什么要在这里用它？**

在深度学习的数据处理中，模型通常不接受“一个样本一个样本”地输入，而是要求**按维度对齐**：

- 模型需要一整块文本 Tensor（形状为 `[Batch, Seq_Len]`）。
- 模型需要一整块标签 Tensor（形状为 `[Batch]`）。

`zip(*batch)` 恰恰完成了这个从“横向存储”（按样本存）到“纵向存储”（按特征存）的转换，方便后续直接调用 `torch.tensor()` 将整组数据转化为张量。

### 8. partial()函数

代码示例（省略部分细节）：

```python
import torch
from torch.utils.data import Dataset, DataLoader
from functools import partial

class IMDBDataset(Dataset):
    """IMDB 文本分类数据集，返回 (text, label)。"""
    def __init__(self, hf_dataset_split):
		...


def collate_fn(batch, tokenizer: Tokenizer, max_length: int = 300):
    """DataLoader 的回调函数：把一批 (text, label) 打包成模型可直接使用的 tensor。

    参数：
    - batch: List[(text, label)]，DataLoader 自动传入
    - tokenizer: 上面实现的 Tokenizer 实例
    - max_length: 每个样本的最大长度
    """

# 创建 Dataset 实例
train_dataset = IMDBDataset(dataset['train'])

# 创建 DataLoader，并把 collate_fn 作为“回调函数”传进去
train_loader = DataLoader(
    train_dataset,
    batch_size=4,
    shuffle=True,
    collate_fn=partial(collate_fn, tokenizer=tokenizer, max_length=500)  # 使用partial绑定参数
)
```

 `partial(collate_fn, ...)`是一种“函数式编程”的思想：

- `DataLoader` 默认只给 `collate_fn` 传一个参数 `batch`。
- 但你的 `collate_fn` 还需要 `tokenizer` 和 `max_length`。
- `partial` 的作用是**预先填好**后面两个参数，生成一个新的函数。这个新函数只需要接收 `batch` 就能运行，完美适配了 `DataLoader` 的接口要求。

### 9. `nn.Embedding` 中的 `padding_idx`参数

```python
self.embedding = nn.Embedding(vocab_size, embedding_dim, padding_idx=padding_idx)
```

核心作用：**告诉模型哪个 ID 是“填充位”，并让该位置的梯度永远保持为 0。**

------

**1. 为什么需要 Padding？**

在处理文本数据时，不同句子的长度通常不一致。为了能把它们打包成一个形状规整的张量（Tensor）进行批量运算，我们会规定一个统一的长度（比如 `max_length=500`）。

- **短句子**：末尾会补上很多 0（或者你指定的 `pad_idx`）。
- **长句子**：会被截断。

这些补上去的 `0` 实际上是没有任何语义信息的“废话”。

------

**2. `padding_idx` 的具体操作**

当你指定了 `padding_idx=0` 时，PyTorch 会在内部执行以下两个逻辑：

1. **初始化为 0**：在嵌入矩阵（Embedding Matrix）中，索引为 `0` 的那一行向量会被初始化为全 0。
2. **冻结更新**：在模型训练（反向传播）过程中，索引为 `0` 的这一行**不参与参数更新**。无论模型怎么训练，这个位置的向量永远是全 0。

------

**3. 在你模型中的连锁反应**

看 `forward` 函数中的这几行代码：

```python
x = self.embedding(input_ids)  # [B, L] -> [B, L, E] （B:batch_size, L:seq_len, E:embedding_dim）
x = x.transpose(1, 2)  # [B, L, E] -> [B, E, L]
x = self.avg_pool(x)  # [B, E, L] -> [B, E, 1]
x = x.squeeze(-1)  # 去掉长度为1的维度 -> [B, E]
```

1. **Embedding 层**：所有 `pad_idx` 对应的位置都变成了全 0 向量。
2. **AdaptiveAvgPool1d 层**：你使用了**平均池化**。如果没有 `padding_idx` 让对应位置变成 0，那些原本无意义的填充位可能会带有随机的初始分值，从而“污染”整个句子的特征表示，导致平均值计算不准。
3. **计算意义**：虽然平均池化依然会计算这些 0（这在数学上其实会稍微拉低平均值），但相比于让填充位参与学习并产生随机干扰，设为 `padding_idx` 要安全得多。

------

**4. 总结**

| **特性**         | **设置了 padding_idx**     | **未设置 padding_idx**           |
| ---------------- | -------------------------- | -------------------------------- |
| **初始值**       | 该索引行固定为 0           | 与其他行一样，随机初始化         |
| **梯度更新**     | 不更新（始终为 0）         | 正常更新，学习填充位的“含义”     |
| **对模型的影响** | 忽略填充干扰，聚焦实际内容 | 填充位可能携带噪声，影响池化结果 |

------

**延伸小贴士**

在更高级的模型（如 **Transformer / BERT**）中，除了 `padding_idx`，通常还会配合一个 **Attention Mask**。那个掩码会直接从数学上彻底抹除填充位的影响，而不只是让它的向量变成 0。

在你目前的简单模型里，设置 `padding_idx` 是确保模型不被“废话”干扰的第一步。
