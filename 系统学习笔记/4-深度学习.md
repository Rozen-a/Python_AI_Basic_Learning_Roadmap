#### 1.6 张量的形状操作

*   `reshape()`: 调整形状
*   `transpose()`: 交换两个维度
*   `permute()`: 重新排列多个维度
*   `unsqueeze()`: 在指定维度上增加1个维度
*   `squeeze()`: 删除大小为1的维度
*   `view()`: 调整张量的形状，需要连续内存
*   `is_contiguous()`: 判断是否内存连续
*   `contiguous()`: 转换为连续内存

```python
import torch

x = torch.randn(2, 3, 4)
print(x.shape)
print(x.size())         # size() 方法和 shape 一样, 返回张量的形状

# 1. 调整形状
x = x.reshape(2, 12)            # 调整为2行12列
print("x.shape1:",x.shape)
x = x.reshape(-1, 3)            # 不限制行数, 列数调整为3列 (会自动计算行数)
print("x.shape2:",x.shape)

# 2. 交换维度
x = torch.randn(2, 3, 4)
x = x.transpose(1, 2)
print(x.shape)

# 3. 重新排列多个维度
# 第3维度变为第1维, 第2维变为第2维, 第1维变为第3维
x = x.permute(2,1,0)
print(x.shape)

# 4. 在指定维度上增加一个维度, 会添加形状为1的维度
x = x.unsqueeze(dim = 2)
print(x.shape)

# 5. 在指定维度上删除一个维度, 会删除形状为1的维度 (如果该维度不存在形状为1的维度, 则返回原张量)
x = x.squeeze(dim = 1)
print(x.shape)

# 6. 调整形状, 需要连续内存
# 经过升维和降维操作, 张量的数据存储位置 (内存) 可能会改变, 所以内存可能不连续
# 使用view方法, 如果内存不连续, 那么会报错
# x = x.view(3,-1)
# print(x)

# 6. 判断是否是连续内存
print(x.is_contiguous())

# 7. 转换为连续内存
x = x.contiguous()
print(x.is_contiguous())

# 8. 调整形状, 需要连续内存
x = x.view(3,-1)
print(x.shape)
```

#### 1.7 张量的拼接操作

*   `cat()`: 张量拼接，按已有维度拼接。除拼接维度外，其他维度大小须相同
*   `stack()`: 张量堆叠，按新维度堆叠。所有张量形状必须一致

```python
import torch

# 创建两个张量
x = torch.rand(2, 3, 4)
y = torch.rand(4, 3, 4)

# 1. cat() 按照指定维度进行拼接
# x和y, 除了0轴维度不一样, 其他轴维度相同
z = torch.cat([x, y], dim=0)
print(z.shape)              # 结果是[6,3,4]

# z = torch.cat([x, y], dim=1)    # 会报错, 因为x和y只有0轴不同, 其他轴维度相同, 只能拼接0轴

# 2. 按照新维度堆叠 (堆叠的张量, 必须形状一致, 不然会报错)
# z = torch.stack([x, y], dim=3)

x = torch.rand(2, 3, 4)
y = torch.rand(2, 3, 4)

z = torch.stack([x, y], dim=2)        # dim是2, z的维度是[2,3,2,4]
print(z.shape)
```

### 2. 自动微分

训练神经网络时，最常用的算法就是反向传播。

在该算法中，参数（模型权重）会根据损失函数关于对应的参数的梯度进行调整。为了计算这些梯度，Pytorch内置了自动微分模块，具体来说就是名为 `torch.autograd` 的自动微分引擎，他支持任意计算图（计算图就是构建好的神经网络）的自动梯度计算：

![image-20260306021829265](https://gitee.com/rozen_gitee/typora-img/raw/master/img/20260306021829380.png)

如何理解自动微分呢？大白话来说，其实就是**自动求梯度**

举个例子（以线性回归为例，如上图所示）

*   假设模型参数是：$y = w \cdot x + b$
*   现在提供了特征值x，目标值y
*   初始化随机 权重w和偏置b
*   通过模型 $y' = w \cdot x + b$ 可以得到拟合结果
*   然后对拟合结果与真实结果求得损失函数
*   接下来利用损失函数，对w和b求偏导，得到梯度下降的梯度

$$
w_n = w_{n-1} - \eta \frac{\partial Loss}{\partial w}
$$

$$
b_n = b_{n-1} - \eta \frac{\partial Loss}{\partial b}
$$



*   然后更新w和b，重新拟合

而自动微分模块，其实就是根据损失函数Loss自动求得权重w和偏置b的梯度。

接下来我们使用这个结构进行自动微分模块的介绍。我们使用 `backward()` 方法实现梯度的计算，`grad` 属性来访问梯度

```python
import torch

# 1. 准备数据：参数与目标值
x = torch.tensor(5) #特征
y = torch.tensor(0.)

# 2. 初始化参数：权重与偏置
w = torch.tensor(1., requires_grad=True, dtype=torch.float32)
b = torch.tensor(3., requires_grad=True, dtype=torch.float32)

# 3. 构建神经网络并输出值
z = w * x + b

# 4. 计算损失
loss = torch.nn.MSELoss()
loss = loss(z, y)

# 5. 反向传播，自动微分，计算梯度
loss.backward()

# 6. 访问梯度
print(w.grad)
print(b.grad)
```

```python
import torch

# 1. 准备数据：参数与目标值
x = torch.ones(2,5)
y = torch.zeros(2,3)

# 2. 初始化参数：权重与偏置
w = torch.randn(5,3, requires_grad=True)
b = torch.randn(3,requires_grad=True,)

# 3. 构建神经网络并输出值
z = torch.matmul(x, w) + b

# 4. 计算损失
loss = torch.nn.MSELoss()
loss = loss(z, y)

# 5. 反向传播，自动微分，计算梯度
loss.backward()

# 6. 访问梯度
print(w.grad)
print(b.grad)
```

### 3. PyTorch 训练模型一般步骤

通过 **PyTorch** 训练一个模型一般可以分为以下 4 个步骤：

**1. 准备数据**

- 自定义 `Dataset` 类
    - 实现`__init__(self)`：加载原始数据，保存数据处理需要的配置
    - 实现 `__getitem__(index)`：根据索引返回对应位置的样本数据
    - 实现 `__len__()`：返回数据集的总样本数
- 使用 `DataLoader` 加载数据
    - 设置 `batch_size`：按批次读取数据
    - 设置 `shuffle=True`：打乱样本顺序，避免模型陷入局部最优

**2. 构建模型**

- 使用 `torch.nn.Module` 搭建神经网络结构
- 在 `forward()` 方法中定义前向计算过程

**3. 定义损失函数与优化器**

- 选择损失函数（如：均方误差 `MSELoss`）用于衡量预测值与真实值的差距
- 选择优化器（如：`SGD`、`Adam`）用于更新模型参数

**4. 模型训练**

- 使用两层循环进行训练
    - 外层：`epoch`（训练轮数）
    - 内层：`step`（每个 batch 的训练次数）
        - `step ≈ 样本总数 / batch_size`
- 每个 step 的训练流程：
    1. 前向计算（`model(x)`）
    2. 计算损失（`loss`）
    3. 清空梯度（`optimizer.zero_grad()`）
    4. 反向传播求梯度（`loss.backward()`）
    5. 更新参数（`optimizer.step()`）

### 4. Dataset 和 DataLoader

一般案例中，送入模型中的是DataLoader中的一批一批的数据，而DataLoader中的数据是从Dataset数据集中获取的。在很多任务中，Dataset数据集已经有别的组织或者框架给我们封装好了，但是也有可能没有给我们封装好，有的时候我们也需要自己从原始数据封装为Dataset供模型训练。

#### 4.1 Dataset

Dataset是Pytorch中的一个抽象类，用于表示数据集。它**允许用户自定义数据集的接口，使得用户可以使用统一的形式来访问数据**。

举个例子：

*   Dataset就像“整理好的快递箱”
*   每个快递箱（Dataset）里装着多个包裹（样本）
*   每个包裹上贴了编号（索引）
*   快递员（DataLoader）能按编号快速找到并取出包裹，不用翻遍整个箱子

**定义方法：**

PyTorch 要求自定义Dataset必须继承 `torch.utils.data.Dataset`，并实现 **3 个核心方法** —— 这 3 个方法就是“数据容器的说明书”，告诉框架“数据有多少、怎么取”。

*   `__init__(self)`：加载原始数据，保存数据处理需要的配置，如样本的大小，总个数等。相当于“把所有包裹装进快递箱”
*   `__len__(self)`：作用是告诉框架，容器中有多少个样本，返回总样本个数即可
*   `__getitem__(self, index)`：通过数据的索引，获取样本。

```python
# 自定义Dataset
import torch
from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self):
        # 1. 初始化数据，例如读取文件
        self.data = ['李云龙','楚云飞','赵刚','丁伟','孔捷','常乃超','魏大勇','秀芹']
        self.total = len(self.data)

    def __getitem__(self, index):
        # 2. 获取索引对应的数据
        return self.data[index]


    def __len__(self):
        # 3. 返回数据集的长度
        return self.total

if __name__ == '__main__':
    dataset = MyDataset()
    print(dataset[1])
```

#### 4.2 DataLoader

DataLoader是 PyTorch 中用于批量加载数据的工具。
它允许用户根据自定义的Dataset对象创建一个数据加载器，用于**批量加载和处理数据**。
DataLoader可以**按照批次大小对数据集进行分割**，并**提供多线程数据加载和预取功能**。

```python
# DataLoader的创建
import torch
from torch.utils.data import DataLoader

# 创建DataLoader
# batch_size: 每次批次的大小（一般是2的倍数）
# shuffle: 是否打乱数据
dataloader = DataLoader(MyDataset(), batch_size=2, shuffle=False)
	# 每次取两个样本（Tensor）装箱，打包成一个data（Tensor）
    # 此处示例使用的是列表而非Tensor，所以返回data的类型也是list而不是Tensor

# 获取批次数据
for data in dataloader:
    print(data)
```
